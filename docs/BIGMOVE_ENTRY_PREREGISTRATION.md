# 가온전선형(대금 폭발 대형 급등) 종목을 +10% 아래에서 사기 — 사전등록 (2026-09-20)

사용자 지시: "18일 가온전선처럼 오른 종목들 찾아서 10% 이하에서 매수한다면 어떻게 매수하는 게
좋은지 찾아줘."

## 0. 왜 새 측정인가 — 직전 결과와 정반대 유형이다

직전 측정(`backtest-agent_20260920-231451_ladder_exit.md`)에서 유일하게 작동한 필터는
**"진입 시점 누적 거래대금이 적을 것"**(+9% 진입 시 73억 미만)이었다. 그런데 기준 사례인
**가온전선 2026-09-18은 +9% 시점 누적대금이 802억으로 그 문턱의 11배**다 — **그 필터로는
절대 못 사는 종목**이다. 즉 사용자가 원하는 건 직전에 찾은 구간과 **다른 유형**이므로
결과를 물려받지 않고 새로 잰다.

기준 사례 실측(2026-09-18 가온전선, 전일종가 264,000):
| 시각 | 사건 | 누적 거래대금 | 경과 | 대금속도 |
|---|---|---|---|---|
| 09:03:51 | +5% | 228.5억 | 3.9분 | 58.6억/분 |
| 09:17:29 | +9% | 802.3억 | 17.5분 | 45.9억/분 |
| 09:18:29 | +10% | 850.9억 | 18.5분 | 46.0억/분 |
| 09:36:05 | +15% | 1,960.6억 | | |
| 09:51:35 | +20% | 2,883.9억 | | |
| 종가 | **+22.73%** (고가 +26.33%) | 7,175억 | | |

(참고: 같은 종목 2026-08-18은 고가 +4.01%, 종가 -2.51%로 **전혀 다른 날**이다. 사용자가
말한 "18일"은 **9월 18일**로 확정.)

## 1. 가설 — 무엇을 재는가

직전 측정은 "누적 거래대금(절대액)"만 봤다. 가온전선은 **짧은 시간에 큰 대금이 쌓였다**는
점이 특징이므로, 이번엔 **대금이 쌓이는 속도**를 본다.

**`value_speed` = 진입 시점까지의 누적 거래대금 ÷ 09:00부터의 경과 분(억/분)**

새 데이터 소스가 아니라 **이미 가진 두 값(누적대금, 진입시각)의 나눗셈**이다 — 새 피처를
발명한 게 아니라 직전 측정의 피처를 시간으로 정규화한 것임을 명시한다.
같이 보는 것: 누적대금(절대액, 직전 측정 것), 진입 시각.

**가설 H**: value_speed가 높을수록 그 종목이 당일 +20% 이상까지 갈 확률이 높다.
(직전 측정의 "누적대금 적을수록 좋다"와 **정면으로 충돌하는 가설**이다 — 둘 중 하나는
틀리거나, 둘이 서로 다른 유형을 가리킨다. 그것 자체가 이번 측정의 답이다.)

## 2. 대상(가온전선형)의 정의 — 숫자로

- **BIG군** = 당일 정규장 고가가 전일종가 대비 **+20% 이상**인 종목·일
  (가온전선 +26.3%가 여기 들어간다)
- **대조군** = +5%를 넘었으나 +20%에 못 간 종목·일 ← **이게 본체다**
- 매수 결정은 **+10% 미만**에서만 한다(사용자 제약). 진입문턱 X ∈ {5%, 7%, 9%}.
- **갭시작 제외**(첫 틱이 이미 문턱 이상이면 "그 아래에서 산다"가 불가). 건수만 따로 보고.

**함정 명시**: "가온전선처럼 오른 종목을 찾아서"는 결과를 알고 뒤돌아보는 것이다. 매수
시점(+10% 미만)에 **똑같아 보였지만 안 간 종목**이 훨씬 많으면 그 특징은 힌트가 아니다.
그래서 모든 표는 BIG군/대조군을 나란히 놓는다. **BIG군만 있는 표는 만들지 않는다.**

## 3. 측정

1. **BIG군이 몇 건인가** (33거래일). 20건 미만이면 판정보류로 끝낸다.
2. 진입문턱 X별로 BIG군 vs 대조군의 `value_speed`·누적대금·진입시각 분포 + 효과크기
   (Cohen's d, AUC) — 직전 측정과 같은 방식.
3. **value_speed 상위 문턱을 IS에서만 뽑아 OOS에 1회 적용**했을 때의 적중률·기대값.
4. 청산은 직전 측정에서 가장 나았던 **전량 +20% 지정가**를 기본으로 하고,
   **가온전선처럼 +20%를 넘어 더 가는 경우를 못 먹는 문제**를 보기 위해
   **종가청산·트레일링 없음 변형**을 같이 낸다(가온전선은 종가 +22.7%라 +20% 익절이 더 나음).
5. 직전 필터(누적대금 **하위**)와 이번 필터(value_speed **상위**)를 **교차표**로 비교 —
   둘이 정말 반대인지, 겹치는지.

## 4. IS/OOS·비용·유의성

- **IS = 8월(18일) / OOS = 9월(15일)**. 문턱은 IS에서만. 가온전선(9-18)은 **OOS에 있다** —
  즉 기준 사례가 홀드아웃에 들어가므로, IS에서 고른 규칙이 그걸 실제로 잡는지 확인 가능.
- 비용 `round_trip_cost_pct` + **1.5배/2배 민감도**(대금이 큰 종목이라 오히려 체결은 쉬운
  쪽 — 직전 측정의 "얇은 호가" 경고와 반대 방향임을 명시).
- 부트스트랩 95% CI + 일자클러스터 SE. 날짜·종목 편중 보고.

## 5. 기각조건 (미리 못박음)

- **(a)** BIG군 < 20건 → 판정보류
- **(b)** value_speed가 BIG군/대조군을 못 가름(|Cohen's d| < 0.2 **그리고** AUC < 0.55)
- **(c)** 문턱 적용 후 **OOS 순수익 ≤ 0**
- **(d)** OOS 부트스트랩 CI가 0을 포함하거나 IS 대비 부호가 뒤집힘
- **(e)** OOS 거래 30건 미만 → 판정보류

문턱을 바꿔가며 통과선을 찾지 않는다. 안 되면 "없다"고 쓴다. **특히 가온전선 한 종목이
좋아 보인다고 그걸 근거로 결론을 만들지 않는다 — 표본 1건은 근거가 아니다.**
