# 2026-08-31 08:00~08:50 웹소켓 세션 테스트 — 절차

목적 두 가지: (1) 같은 appkey로 WebSocket 연결이 2개면 충돌하는지, (2) NXT가 08:00부터
프리마켓 체결을 0B로 실시간 밀어주는지. 담당: monitoring-agent 주도, data-agent 협조.
장 시작(09:00) 전에 끝내는 이유는 실패해도 잃을 게 없기 때문이다.

## 사용자가 할 일 — 이거 하나뿐

**08:00에 평소처럼 소피증권을 켠다.** 그 외엔 아무것도 안 해도 된다. 08:50까지 그대로
켜두면 된다(끄지 마라 — 09:00 장 시작에 그대로 쓸 것이므로).

## 진행자(monitoring-agent)가 할 일 — 시간순

### 08:00 — 소피증권 기동 확인
```
python -m backtesting.sophie_prelaunch_watch --until-hhmm 0850
```
가만히 켜두면 알아서 `dist/logs/websocket.log`·`app.log`·`/api/market`을 관찰하며
JSONL로 기록하고 화면에도 실시간 출력한다(관찰만 — 아무것도 안 건드림). LOGIN/REG
연결 여부는 `ws_status` 이벤트로 뜬다.

### 08:05~08:15 — NXT 프리마켓 관찰
위 스크립트를 계속 띄워둔 채로 지켜본다. `tick_heartbeat`의 틱 카운터(N)가 이 구간에
늘면 NXT 프리마켓 체결이 0B로 들어온다는 뜻 — `market_movers` 이벤트로 어떤 종목이
움직였는지도 대략 짚힌다(정확한 종목·시각·건수 단위 로그는 소피증권 코드에 없어서
이 정도가 외부에서 볼 수 있는 최선이다).

### 08:20 — 두 번째 연결 시도(핵심 테스트)
**새 터미널**에서(위 관찰 스크립트는 계속 켜둔 채로):
```
python -m backtesting.websocket_collision_probe --minutes 25 --hard-stop-hhmm 0850
```
같은 appkey로 삼성전자(005930) 1종목만 구독한다. 이 순간 관찰 스크립트 화면에서
`ws_status`에 "연결 끊김"이 뜨는지 본다 — 그게 뜨면 세션 제한이 있다는 뜻이다.
탐침 스크립트 자체의 `close`/`login_response`/`reg_response` 로그도 같이 본다(둘 다
살아있는지, 탐침 쪽이 거부되는지도 그 자리에서 구분된다).

### 08:20~08:50 — 관찰 유지

### 08:50 — 반드시 종료
탐침(`websocket_collision_probe`)은 `--hard-stop-hhmm 0850`로 **자동 종료**되지만,
확인 삼아 화면에 `close`/`hard_stop_reached` 로그가 찍혔는지 눈으로 확인한다. 혹시
아직 떠 있으면 Ctrl+C로 즉시 종료. 관찰 스크립트(`sophie_prelaunch_watch`)도
`--until-hhmm 0850`로 자동 종료된다. **09:00엔 소피증권 하나만 남아있어야 한다.**

## 결과 판정
| 관찰 | 판정 |
|---|---|
| 탐침 연결 뒤에도 소피증권 `ws_status`가 "연결됨" 유지, 탐침도 `push` 수신 | 세션 제한 없음 → 앱키 추가 불필요, 별도 호가 수집기로 진행 |
| 탐침 연결 직후 소피증권 `ws_status`에 "연결 끊김" | 세션 제한 있음 → 앱키 추가 또는 feed.py에 얹는 방식 검토 |
| 탐침의 `login_response`/`reg_response`가 애초에 실패(return_code≠0) | 역시 제한 있음(두 번째 연결 자체가 거부) |
| 08:05~08:15 `tick_heartbeat`가 늚 | NXT 프리마켓 체결 실시간 수신 확인 |
| 08:05~08:15 `tick_heartbeat` 안 늚 | 실시간도 정규장만(0B는 09:00부터) |

## 안전장치 요약
- 탐침·관찰 둘 다 시각 기반 하드컷(`--hard-stop-hhmm`/`--until-hhmm`) — 잊어도 자동 종료
- 탐침은 재연결 로직이 없다(끊기면 그대로 끝) — 관찰이 오염되지 않게 의도적으로 뺐다
- 소피증권 코드는 이 테스트에서 한 줄도 안 건드린다
