# 삼화콘덴서 +20% 상승일의 공통점 — 사전등록 (2026-09-20)

사용자 지시: "삼화콘덴서 20% 이상 오른 날의 공통점도 찾아줘."

## 0. 함정을 먼저 못박는다

**"+20% 간 날만 모아 공통점을 찾는 것"은 답을 알고 뒤돌아보는 것이다.** 같은 특징을
가졌는데 +20% 못 간 날이 훨씬 많으면 그건 공통점이 아니라 **그 종목의 평소 모습**일 뿐이다.
앞선 두 측정에서 반복 확인한 함정이므로 이번에도 같은 규율을 적용한다:

- **사건군** = 고가가 전일종가 대비 +20% 이상인 날
- **대조군** = 그 외 모든 날 (같은 종목, 같은 기간)
- **사건군만 있는 표는 만들지 않는다.** 안 갈리면 "공통점 없음"이 정답이다.

## 1. 데이터 · 표본

`data/stocks/daily/001820.csv` (삼화콘덴서) **2019-04-23 ~ 2026-09-18, 1,820거래일**.
사건군 **17일**(고가 +20%↑, 기저율 0.93%), 종가 기준으로는 9일.

**데이터 검증 완료**: 2026-06-30 151,000원 → 2026-07-30 57,800원의 급락이 액면분할/권리락인지
확인 → **아니다**(하루 -30% 초과일 0건, 시가갭 -25% 초과일 0건, 일일 변동폭이 전부 제도
한도 안). 정상 하락의 연속이므로 수정주가 문제 없음.

틱 데이터는 33일(2026-08-04~09-18)뿐이라 사건 2건(08-13, 09-11)만 포함 — **틱 분석은
"2건짜리 참고"로만 쓰고 통계적 결론에 쓰지 않는다.**

## 2. 사건의 시간 분포를 먼저 본다 (독립성 점검)

17건 중 12건이 2026년에, 그중 5건이 2026년 5월에 몰려 있다. **사건이 독립적이지 않고
국면(군집)으로 온다**는 뜻이므로:
- 연도별/월별 분포를 먼저 보고한다
- **2026년 5~6월 군집을 제외해도 공통점이 유지되는지** 따로 확인한다
- 유지 안 되면 "공통점이 아니라 그 시기의 특수 국면"이라고 명시한다

## 3. 무엇을 보는가 (전부 그 전날까지의 정보만)

당일 데이터는 결과이므로 예측변수에 쓰지 않는다. 전일 종가까지로 계산:
1. **전일 등락률**
2. **직전 5일 / 20일 수익률** (모멘텀)
3. **전일 거래량 ÷ 직전 20일 평균 거래량** (거래량 급증)
4. **직전 20일 일간 변동성**(표준편차)
5. **직전 250일 고가 대비 현재 위치**(신고가 근접도)
6. **직전 10일 안에 다른 +20% 사건이 있었는가**(군집 여부)

별도로, **당일 시가갭**(시가/전일종가)은 "장 시작 후에는 알 수 있는 정보"이므로
**따로 표시**해서 보고한다(전날 밤에는 못 쓰는 정보임을 명시).

## 4. 판정 기준

- 효과크기 **Cohen's d**와 **AUC**를 직접 계산. |d| < 0.2 이고 AUC < 0.55면 "공통점 아님".
- **조건을 걸었을 때의 적중률**을 반드시 같이 낸다 — 기저율 0.93%가 몇 %로 오르는가.
  올라도 **여전히 낮으면 "실전에서는 못 쓴다"고 명시**한다.
- 사건 17건은 통계적으로 작다 — **"검증됨"이라 쓰지 않고 관찰로만 보고**한다.
