## 구조적 이유 — 천장이 0이다

ML 게이트는 `detect_entries` 가 규칙으로 만든 후보 안에서만 고른다.
후보 집합이 마이너스면 아무리 잘 골라도 천장이 0이다. 실측이 정확히 그랬다.
**규칙을 손봐서 나아질 수 있는 문제가 아니었다.**

- DuckDB 도입 — `rank1` 18.8배, 조건별 3.1~4.8배, 결과 불일치 0

## 배운 것

1. **규칙이 후보를 만들면 ML 의 천장은 그 후보 집합이다.**
2. **좋아 보이는 숫자는 대개 측정이 틀린 것이다.** 오늘 3번 다 그랬다.
3. **폴드 개수가 많다고 좋은 게 아니다.** `new_high` 제거가 3/4 였는데 합산은 나빴다.
4. **가설이 값을 요구하지 않는 파라미터는 전부 과적합 통로다.**
5. **상관이 높다고 효과 방향이 같지 않다.** `new_high`↔`no_drawdown` φ=0.437 인데 반대였다.
