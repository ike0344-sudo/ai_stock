# +20% 급등주 2라운드 — "안 터졌는데 지금 불붙는 중" 2축 조합 (사전등록, 2026-09-24)

1라운드: `state/agent_reports/backtest-agent_20260920-190424_leader_20pct_precursor.md`
(기저율 23.8%, 단일 문턱 누적대금 ≤82.4억은 OOS에서 무너짐 — 방향은 있으나 규칙 없음)

## 0. 가설

1라운드에서 **따로따로는 IS→OOS 방향이 재현된 신호 3개**가 나왔다:

| 신호 | 방향 | 전체 AUC | IS → OOS |
|---|---|---|---|
| 누적 거래대금 | **적을수록** A군 | 0.662 | 0.681 → 0.640 |
| `w10_tick_speed` | **빠를수록** A군 | 0.633 | 0.585 → **0.717** |
| `vs10_value_surge` | **클수록** A군 | 0.627 | 0.594 → **0.702** |

**가설 H**: 앞 둘은 모순이 아니라 같은 그림의 두 면이다 — **"총량은 아직 안 쌓였는데(저대금)
지금 이 순간 체결이 빠르다(고속)" = 막 불붙는 자리**. 두 축을 곱하면 단일 문턱보다 낫다.

**단, 이 가설이 데이터에 안 맞으면 안 맞는다고 쓴다.** 두 축이 사실상 같은 정보이거나
(상관이 높거나), 조합이 단일보다 못하면 그대로 보고한다.

## 1. 표본 — 이 설계를 버틸 수 있는가를 먼저 묻는다

1라운드 조건 그대로 고정(갭시작 제외 유지):

| | 전체 | A군(+20% 달성) |
|---|---|---|
| IS (08-04~08-20) | 159 | **36** |
| OOS (08-21~08-28) | 72 | **19** |

**IS 양성 36건 위에 2축 문턱을 얹는 것은 위험하다.** 단일 문턱도 OOS에서 무너진 표본이다.
그래서 다음을 **미리** 못박는다:

- **격자는 최대 2×2 = 4칸.** 축당 문턱 2개까지. 더 넓히지 않는다.
- **IS 칸의 A군이 10건 미만이면 그 칸은 "판정 불가"로 표시**하고 선택 후보에서 제외한다.
- 4칸 전부 판정 불가면 **"표본이 이 설계를 못 버틴다"로 결론내고 멈춘다.** 억지로 안 돌린다.

## 2. 축과 문턱 (IS에서만 결정)

- **축1 = 누적 거래대금**, 방향 `≤`, 문턱 후보 2개: **IS 중앙값 / IS Q1**
- **축2 = 체결 속도계열**, 방향 `≥`, 문턱 후보 2개: **IS 중앙값 / IS Q3**

**축2를 둘 중 무엇으로 할지도 IS로 정한다**: `w10_tick_speed`와 `vs10_value_surge`의
**IS auc_abs가 높은 쪽 하나**를 본 격자에 쓴다. 나머지 하나는 **민감도(참고)** 로만 같은
격자를 돌려 보고하고 **선택에 쓰지 않는다**. 두 축의 상관계수도 같이 보고한다
(상관이 높으면 "두 축"이 아니라 사실상 한 축이다).

**선택**: 4칸 중 **IS 순수익 1등 한 칸**만 OOS에 **1회** 적용. OOS 보고 다시 고르지 않는다.

## 3. 같이 답할 것 — 순위 구간별 **기대값**

1라운드는 순위 구간별 *적중률*만 냈다(1~10위 16.0%로 최저). 그런데 "드물지만 크다"도
같이 발견했다(T0 20위 안 A군은 마감 9위, 20위 밖 A군은 마감 32위).

→ **순위 구간(1~10 / 11~20 / 21~50 / 51위~)별로 적중률과 순수익(기대값)을 나란히** 낸다.
**둘이 갈리면 그 자체가 답이다**(1라운드 §7 갭시작에서 확인된 교훈: 적중률 57.1%인데
기대값 -2.75%). 순위는 **"117종목 내 순위"**라고 표마다 못박는다 — 시장 전체 아니다.

## 4. 고정 조건 (1라운드 그대로)

- 갭시작 제외 유지(1라운드 §7에서 잡은 오염 — 되돌리지 않는다)
- IS 08-04~08-20 / OOS 08-21~08-28, 문턱은 IS에서만
- 정규장 필터, 일봉 종가 괴리 1% 초과 제외, `PRICE_EPS` 부동소수 보정 유지
- 진입 = +10% 최초 도달 틱, 청산 = +20% 지정가(미달 시 종가), 손절 없음
- 비용 = `round_trip_cost_pct`(수수료×2 + 거래세 + 슬리피지×2), **총수익·순수익 나란히**
- **슬리피지 1.5배 민감도 필수**(1라운드에서 이걸로 부호가 뒤집혔다)
- 유의성은 **일자 단위로 묶은 일별평균의 분산**(`_day_clustered_mean_se`) + 부트스트랩 CI

## 5. 기각조건 (미리 못박음)

- **(a) OOS 순수익 ≤ 0**
- **(b) OOS가 1라운드 단일문턱(누적대금 ≤ IS Q1)보다 못함**
- **(c) 무조건진입(기저율 23.8%, 231건 전체) 대조군을 못 넘음**
- (d) 슬리피지 1.5배에서 부호가 뒤집힘
- (e) §1의 표본 규칙(IS 칸 A군 10건 미만)에 걸려 선택 가능한 칸이 없음

하나라도 걸리면 "2축 조합은 안 된다"로 명시한다. 문턱을 바꿔가며 통과선을 찾지 않는다.

OOS와 9월에 각각 1회씩** 적용해 **두 개의 독립 홀드아웃**에서 보는 것이 단일 홀드아웃보다
