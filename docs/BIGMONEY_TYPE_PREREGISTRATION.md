# "돈이 크게 터지며 가는 종목"의 +10% 이하 공통점 — 사전등록 (2026-09-20)

사용자 지시: "돈이 크게 터지며 가는 종목 체결데이터에서 10% 이하에서 공통점을 분석해줘."

## 0. 왜 이 측정인가

앞선 두 측정에서 **+20% 급등은 두 유형으로 갈린다**는 게 나왔다:
- **유형A(얇은 급등)**: 진입 시점 누적대금이 적음 → 이미 규칙을 냈다(+9%·73억 미만·09:10
  이전, OOS +3.04%). `backtest-agent_20260920-232957_bigmove_entry.md`
- **유형B(대금 폭발)**: 가온전선(+9% 시점 802억), 삼화콘덴서(152억/187억) — **유형A 규칙에
  전부 걸러진다.** 이 유형 안에서는 아직 성공/실패를 가르는 걸 찾지 않았다.

앞선 교차표에서 유형B(고대금)는 +9% 진입 329건 중 61건만 +20%에 도달(18.5%)하고
**평균 -0.31~-1.02%로 손실**이었다. **이 유형을 살릴 수 있는 조건이 있는지가 이번 질문이다.**

## 1. 대상 정의 (숫자로)

- 진입문턱 X ∈ {5%, 7%, 9%} (전부 +10% 미만), 갭시작 제외(그 아래에서 살 수 없음)
- **유형B(대금 폭발)** = 진입 시점 누적 거래대금이 **IS 상위 50%**(= 저대금 문턱 초과)
- **성공군** = 그 뒤 +20% 도달 / **실패군** = 미도달 ← **대조군이 본체**
- **성공군만 있는 표는 만들지 않는다.** 안 갈리면 "공통점 없음"이 정답이다.

## 2. 무엇을 보는가 — 전부 진입 직전까지의 정보만

기존(이미 잰 것): 누적대금, 진입시각, 대금속도(억/분), 체결속도(10/30초),
체결금액증가율(3/10초), 진입가가 문턱을 넘은 정도.

**이번에 추가하는 3개** — 새 데이터 소스가 아니라 **이미 가진 틱/일봉에서 뽑는 파생값**이며,
"돈이 터진다"를 절대액이 아니라 **그 종목 기준으로 정규화**하기 위함임을 명시한다:
1. **대금배율 = 진입시점 누적 거래대금 ÷ 전일 하루 거래대금**
   — "아직 오전인데 벌써 어제 하루치의 몇 배"가 절대액(억원)보다 종목 크기에 덜 휘둘린다.
   전일 데이터만 쓰므로 완전히 인과적.
2. **평균 체결 크기 = 누적 거래대금 ÷ 누적 체결 건수** — 큰손이 사는지 잔주문이 많은지.
3. **시가 등락률**(시가÷전일종가) — 장 시작에 이미 알 수 있는 정보.
   (개장 전에는 못 쓰는 정보이므로 그렇게 표시한다.)

재확인용으로 **매수비율(buy_ratio)** 도 한 번 더 넣는다 — 앞선 세 라벨에서 죽었지만
이 부분집합에서도 죽는지 표에 남긴다(지시 관행).

## 3. 판정

- 효과크기 **Cohen's d + AUC** 직접 계산. |d| < 0.2 **그리고** AUC < 0.55면 "공통점 아님".
- **IS(8월)에서만 문턱을 고르고 OOS(9월)에 1회 적용**. IS/OOS 방향이 다르면 기각.
- 조건 적용 후 **+20% 적중률과 순수익(비용 반영)** 을 같이 낸다. 적중률만 올리고 돈이
  안 되면 "돈은 안 된다"고 쓴다.
- 청산은 직전 측정과 같은 **전량 +20% 지정가**를 기본, 참고로 종가청산도 같이.

## 4. 기각조건 (미리 못박음)

- **(a)** 유형B 성공군이 20건 미만 → 판정보류
- **(b)** 어떤 피처도 |d|≥0.2 또는 AUC≥0.55를 못 넘음 → "공통점 없음"
- **(c)** 문턱 적용 후 **OOS 순수익 ≤ 0**
- **(d)** OOS 부트스트랩 CI가 0을 포함하거나 IS 대비 부호가 뒤집힘
- **(e)** OOS 거래 30건 미만 → 판정보류

문턱을 바꿔가며 통과선을 찾지 않는다. **유형A 규칙(OOS +3.04%)보다 나은지도 같이 보고**하고,
못 넘으면 "유형B는 유형A보다 못하다"고 그대로 쓴다.
