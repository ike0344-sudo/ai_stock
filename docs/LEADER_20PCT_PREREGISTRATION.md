# 당일 +20% 종목을 +10%에서 미리 사기 — 사전등록 (2026-09-20)

사용자 질문: "당일 +20% 가는 종목을 +10% 이하에서 미리 사고 싶다. 그때 거래대금 순위가
보통 몇 위였고 거래대금은 얼마나 터졌나? 그 전에 살 수 있는 힌트를 찾아줘."

결과를 보기 전에 방법·기각조건을 여기 먼저 못박는다.

## 0. 지시 검증 — 틀린 것 3개 정정하고 시작한다

| 지시문 | 실제 | 처리 |
|---|---|---|
| "114종목 × 18거래일" | **117종목**(디렉터리 117개, 빈 것 0개), **2,017 종목·일**(117×18=2,106이 아님 — 109종목만 18일 전부, 8종목은 4~12일만 있음) | 117종목/2,017 종목·일로 진행, 표에 실제 수치 명시 |
| "`data/stocks/tick_al/README.md`가 경고" + 컬럼 `time` | README는 원본 API 필드명 `cntr_tm`으로 써 있으나 **저장된 컬럼명은 `time`**(HHMMSS 문자열) — 지시문이 맞고 README 표기가 옛 이름 | 지시문대로 `time` 사용, 정규장 필터 규칙은 README대로 준수 |
| "`results/rank_timeline_sample.json` 같은 실제 순위 기록이 쓸 만한지 확인" | **못 쓴다.** 그 파일은 **테마 점수 타임라인**(theme/score/leader/chgtop)이지 종목별 거래대금 순위가 아니다. 날짜도 2026-07-01. `kospi-theme-engine/results/rank_timeline_full_*.json`(8월 19일치)도 같은 테마 구조이고 종목을 **이름**으로만 담아 코드 조인이 불가. `backtesting/trading_value_ranking.py`는 실시간 API 폴러라 과거 순위 아카이브가 없다 | **시장 전체 순위는 재현 불가 → "117종목 내 순위"로만 낸다.** 모든 표·본문에 못박는다 |

지시문 중 맞는 것: 원본이 시간 역순(19:59:59→08:00:00)인 것, 정규장 필터 필요,
전일종가는 일봉 캐시(`data/stocks/daily/`, 2,575종목) 사용 — 전부 확인함.

## 1. 정의 (숫자로 못박는다)

전일종가 `pc` = `data/stocks/daily/<code>.csv`에서 해당 날짜 **직전** 거래일의 `close`.

- **T0(결정시점)** = 정규장(09:00:00~15:30:00) 안에서 체결가가 **처음으로 `pc×1.10` 이상**이
  된 틱의 시각. 이 틱 가격이 진입가.
- **A군** = T0 이후(T0 틱 포함) 정규장 안에서 체결가가 **`pc×1.20` 이상**에 닿은 종목·일.
- **B군(대조군)** = T0는 있었으나 `pc×1.20`에 못 닿은 종목·일.
- **미통과** = +10%에 아예 못 닿은 종목·일 (A도 B도 아님, 기저율 계산의 분모 맥락으로만 보고).
- **갭 예외** = 정규장 첫 틱이 이미 `pc×1.10` 이상인 경우 → T0의 사전 관측창이 없거나
  짧다. **별도 집계**해서 보고하고, 첫 틱이 이미 `pc×1.20` 이상이면 "≤+10%에 살 방법이
  애초에 없음"으로 분리(A군 수익률 통계에서 제외, 건수는 보고).

**"+10% 이하에서 미리"의 해석(구현결정)**: T0는 +10%를 *막 넘는 순간*이므로 진입가는
사실상 +10% 근처다. 그보다 더 싸게(예: +5%에) 사려면 "+10%를 곧 넘을 것"까지 예측해야
하는 **다른(더 어려운) 문제**가 된다 — 이번 측정의 결정시점은 T0로 고정하고, 모든
예측변수는 **T0 직전까지의 정보만** 쓴다(T0 틱 자체도 피처에 안 넣는다).

**틱 데이터의 이점 명시**: 봉 기반 연구와 달리 여기선 체결 순서가 원본에 그대로 있어
"+20% 먼저냐 종가 먼저냐" 같은 봉내부 경로 근사가 **필요 없다**. 정확히 판정한다.

## 2. 표본 규칙 — 0단계에서 멈출 수 있다 (지시대로)

- **A군 < 20건이면 1~3단계를 진행하지 않고 건수만 보고한다.**
- A군 ≥ 20이어도 **IS 또는 OOS의 A군이 각각 10건 미만이면 문턱 도출(3단계 선별규칙)은
  생략**하고 전체표본 기술통계 + 효과크기까지만 낸다. 이 규칙을 결과 보기 전에 박는다.
- A:B 비율(= +10% 통과 시 +20%까지 가는 비율, **기저율**)을 가장 먼저 보고한다.

## 3. IS/OOS 분할

`shooting_precursor.TRAIN_DATES`(08-04~08-20, 12일) = IS,
`TEST_DATES`(08-21~08-28, 6일) = OOS — **큐(1)~(6)이 전부 쓴 분할을 그대로 재사용**한다.
근거: (i) 시간순 분할이라 미래누수 없음, (ii) 기존 6개 리포트와 직접 비교 가능,
(iii) 새로 나누면 그 선택 자체가 자유도가 된다. **문턱·피처선택은 IS에서만**, OOS는 1회 적용.

## 4. 측정 항목

**1단계(사용자가 물은 그대로, T0 시점 기술통계)** — A군/B군 **나란히**:
- (a) **거래대금 순위** — T0 직전까지의 누적 거래대금으로 그날 그 시각 기준 117종목 내 순위
  (같은 벽시계 초에서 비교). 중앙값·사분위.
- (b) **누적 거래대금**(억원) — 같은 형식.
- (c) **T0 시각 분포** — 09시대/10시대/… 구간별.

**2단계(본체)**: A군 vs B군이 실제로 갈리는가.
- 효과크기: **Cohen's d**(큐(4)에서 쓴 것) + **AUC**(큐(1)에서 쓴 것) 둘 다 직접 계산.
- Mann-Whitney U p값도 내되, **A군 사건의 날짜·종목 편중을 같이 보고**하고 편중되면
  p값을 믿지 말라고 명시(큐(3)에서 t값 과신을 스스로 잡아냈던 것과 같은 규율).

**3단계(T0 이전 힌트)**: 큐(1) 피처를 그대로 재사용, 관측창은 [T0−W, T0):
- 살아남았던 것: `tick_speed`(10/20/30/60초), `value_surge`(1/3/5/10초)
- 죽었던 것도 이 라벨에서 한 번은 재측정(지시대로 표에 남김): `buy_sell_gap`,
  `intensity_change`, `buy_ratio`
- 새 피처 발명 금지. 1단계의 (a)(b)(c)도 그 자체로 T0 이전 정보라 선별축 후보로 같이 본다.

## 5. 비용·기대값 (B군 손실이 본체)

왕복비용 = `t0_forward_return.round_trip_cost_pct` 그대로
(수수료 0.015%×2 + 거래세 0.23% + 슬리피지 max(0.1%, 1틱)×2). 슬리피지 실측
(`backtest-agent_20260901-190000_slippage_measurement.md`: 중앙값 0.109%, p75 0.160%)이
가정보다 **크다**는 결과가 이미 있으므로, 이 상수는 낙관이 아니라 하한 근사임을 명시한다.

**청산 2변형, 둘 다 낸다**:
- **V1(사용자 계획)**: `pc×1.20` 지정가 매도(A군은 정의상 체결), 못 닿으면 **종가 청산**.
  손절 없음.
- **V2(진단용)**: 목표가 없이 **전원 종가 청산**. V1의 "+20%에 정확히 판다"는 낙관을
  제거했을 때 뭐가 남는지 보기 위함.

기대값 = 전체 +10% 통과 표본에 대한 **평균 순수익**(A군 이득 × 기저율 + B군 손익 ×
(1−기저율)). 총수익·순수익 나란히. V1의 "+20% 지정가 체결 가정"은 유리한 가정임을 명시한다.

## 6. 데이터 검증 (측정 전 필수)

- 일봉 종가 vs 틱 정규장 마지막 체결가 대조 → **불일치율 보고**(수정주가/분할 반영 차이
  탐지). 크게 어긋난 종목·일은 제외하고 제외 건수를 보고한다.
- 전일종가가 없는 첫 거래일·신규 종목은 제외(건수 보고).
- 정규장 필터 전후 행수 보고(README 경고 준수 증거).

## 7. 기각조건 (미리 못박음, 결과 보고 안 바꿈)

하나라도 걸리면 그 항목은 "힌트 없음/안 됨"으로 명시한다:
- **(a) A/B가 안 갈림** — 모든 축에서 |Cohen's d| < 0.2(미미 등급) 이고 AUC가 0.55 미만,
  또는 IS에서 갈린 방향이 OOS에서 유지되지 않음.
- **(b) 문턱을 걸어도 순수익 기대값 ≤ 0** (V1 기준. V2도 같이 보고).
- **(c) 표본 미달** — A군 < 20건(전체) 또는 IS/OOS 각 10건 미만(§2).

되는 쪽으로 재해석하지 않는다. 문턱을 바꿔가며 통과선을 찾지 않는다. 안 되면 "없다"고 쓴다.

## 8. 알려진 한계 (결론에 같이 적는다)

- **117종목 내 순위** — 시장 전체 순위 아님(§0). 소피증권 실거래 순위(ka10032, KRX+NXT
  통합)와 다르다.
- **유니버스 선택편향** — 이 117종목은 그 기간 거래대금 상위권 위주로 뽑힌 집합이라
  +20% 사건의 기저율이 시장 전체보다 높게 나올 수 있다. 시장 전체에 그대로 외삽 금지.
- **18거래일뿐** — 계절성·국면 변화를 못 본다. 일자클러스터 자유도가 근본적으로 작다.
- **생존편향** — 현재 살아있는 종목만.
- 호가잔량 없음 — 매물벽/체결강도의 직접 관측 불가(체결로만 간접 추정).
