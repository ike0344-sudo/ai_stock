## 0. 사용자 지시

## 1. 착수 전 정직한 경고 — 이 라벨은 이미 기각됐다

| 항목 | 선행 결과 |

| **온셋격리 후** | OOS **0.639** — 엣지의 **46.4%가 "이미 랠리 중"이라는 자명한 정보** |

그것이 없으면 이 측정은 할 이유가 없다.

## 2. 넘어야 할 선 (결과 보기 전에 못 박는다)

### 【정정】 비용은 고정값이 아니다 — 이 문서 초안에서 내가 틀렸던 부분

초안에 **"왕복 0.52% = 수수료 0.015%×2 + 세금 0.23% + 슬리피지 0.1%×2"**라고 썼는데
**산수가 안 맞는다** — 그 합은 **0.46%**다. 구현하다 테스트가 0.46%를 뱉어서 발견했고,
선행 리포트(`t0_forward_return.md` §2)를 다시 읽어 원인을 확인했다:

> 슬리피지는 편도마다 **`max(0.1%, 1틱/가격)`** 을 적용한다. KRX 호가단위표 기준이라
> **가격대별로 다르다**: 5,000원 0.66% / 50,000원 0.66% / **91,500원(표본 중앙값) 0.48%** /
> 200,000원 0.76%. **표본 전체 평균이 0.524%**였던 것이지 고정 상수가 아니다.

→ 고정 0.46%로 계산하면 **저가주 비용을 크게 과소평가**한다(낙관 편향).
이번 라벨은 **진입가마다 비용을 따로 계산**한다. 기존 `backtesting/t0_forward_return.py`의
`round_trip_cost_pct`와 **값이 일치하는지 테스트로 강제**한다(같은 저장소 안에서 같은
전략이 다른 성적을 내면 안 된다).

아래 본전 승률 표는 **평균 비용 0.52% 기준의 어림값**이다 — 실제 판정은 종목별 비용으로 한다.

| 손절 | 이기면 | 지면 | **본전 승률** |
|---|---|---|---|
| -0.5% | +1.48% | -1.02% | **40.8%** |
| -1.0% | +1.48% | -1.52% | **50.7%** |
| -2.0% | +1.48% | -2.52% | **63.0%** |

선행 최고 조건의 승률이 44.3%였다 → **-1% 손절 기준 6.4%p 모자람**.
-0.5% 손절은 본전선이 낮아 보이지만, 선행 실측에서 **손절을 좁히면 손절률이
65.8~74.7%로 폭증**(재탈환 연구)해 무승부가 전부 손절로 바뀌었다. 세 손절을 다 만들되
**어느 것을 쓸지는 IS에서만 정하고 OOS에 1회 적용**한다.

## 3. 이번에 실제로 다른 것 (이게 없으면 안 한다)

| # | 선행 | 이번 | 왜 중요한가 |
|---|---|---|---|
| 1 | 라벨 = "5분 안 **최고가**가 +2% 닿았나" | 라벨 = **어느 barrier를 먼저 쳤나 + 실현 수익률** | 선행 라벨은 **손절을 먼저 맞은 뒤 나중에 +2% 가도 양성**이었다. 틱은 순서를 정확히 아는데 그걸 안 썼다 |
| 2 | 적중률 라벨 → 수익은 별도 계산 | **라벨 자체가 비용 반영 실현 수익률** | "적중률≠수익성" 함정에 17회 중 4번 걸렸다. 라벨이 수익이면 구조적으로 안 걸린다 |
| 3 | 온셋격리 안 함(사후 민감도로만 확인) | **온셋격리를 기본값으로** | 선행에서 엣지의 46%가 이것 때문에 가짜였음이 판명 |
| 4 | 진입가 = T0 가격 | **진입가 = T0 이후 첫 체결가** | 실측 슬리피지 T0+1초 +0.123%p. T0 가격 진입은 낙관적 |
| 5 | 117종목 × 18일, 지표 14개 | 168종목 × 33일, 지표 80개 | 표본 2.4배 |

**1번이 핵심이다.** 나머지가 다 무의미해도 1번만으로 측정할 값이 있다 —
"틱이 봉보다 나은 유일한 지점"이기 때문이다.

## 4. 라벨 정의 (구현 명세)

```
진입:  t 시점 신호 → t 이후 첫 체결가를 진입가 p0 로 한다 (t의 체결은 안 씀)
익절:  p0 × 1.02
손절:  p0 × (1 - s),  s ∈ {0.005, 0.01, 0.02}
만기:  진입 후 300초 → 그 시점 가격으로 청산
판정:  익절·손절 중 **먼저 닿은 쪽**. 틱 순서로 판정한다.
비용:  왕복 0.52% 차감 (configs/default.yaml cost)
```

산출 라벨 (진입지점당):
- `barrier__s{S}` : 어느 쪽을 먼저 쳤나 (`tp` / `sl` / `expire`)
- `net_return__s{S}` : 비용 차감 실현 수익률 ← **이게 본체**
- `hit_2pct_300s` : 선행과 같은 정의(손절 무시, 최고가 도달) ← **선행 재현 확인용으로만**
- `fwd_return__300s` : 단순 300초 후 수익률 (대조군)

### 같은 초에 익절·손절이 둘 다 닿는 경우
1초 격자는 초당 고가/저가만 알아서 순서를 모른다. **이 경우가 몇 %인지 측정해
리포트에 쓴다.** 5% 미만이면 보수적으로 **손절 우선**으로 처리하고 그 사실을 명시한다.
5% 이상이면 해당 초만 틱 원본으로 내려가 판정한다.
(에이전트 지침: "봉 내부 경로 문제 — 실제로 영향이 있는지 코드로 확인 가능")

## 6. 기각조건 (하나라도 걸리면 기각으로 보고한다)

- **(a)** 최선 규칙의 **OOS 순수익 ≤ 0**
- **(b)** OOS 순수익이 **상시진입 대조군보다 낮음** (선행에서 실제로 이게 걸렸다)
- **(c)** OOS 순수익의 부트스트랩 95% CI가 **0을 포함**
- **(d)** IS→OOS 승률이 **본전 승률 아래로 떨어짐**
- **(e)** 온셋격리 후 엣지가 **절반 이하로 붕괴**
- **(f)** 슬리피지 1.5배(실측 꼬리 반영)에서 **부호가 뒤집힘**
- **(g)** 규칙이 선택한 표본이 **30건 미만**이거나 **특정 2~3종목·1~2일에 집중**
