# 청산설계(MAE·노이즈바닥·손절/목표 격자) 사전등록 (2026-08-31, strategy-agent)

## 0. 모집단 — 25위+1등 조건 대신 SHOOT 라벨 전체를 쓴다(내 판단, 이유 명시)
CEILING의 n=47(_AL)/52(KRX)는 통계적으로 너무 작다. 이번 질문("이 시간척도
자체가 성립하나")은 **어떤 진입필터를 쓰든 공통으로 걸리는 문제**이므로,
필터를 빼고 **SHOOT 라벨 전체**(_AL, 106/117종목 현재분)를 모집단으로
쓴다 — 표본이 수십만 건대라 IS/OOS로 쪼개도 충분하다. CRASH는 이번
분석 범위 밖(롱 전용 +3~5%/-2% 구조를 보는 것이므로).
**주의(CEILING과 같은 경고 그대로 승계)**: SHOOT 라벨 자체가 미래참조라
"실제로 낼 수 있는 진입"이 아니다 — 이번 측정도 "완벽한 진입을 가정했을 때
청산구조가 성립하는가"를 보는 이론적 분석이지 실현 가능한 전략 성과가

## 1. 측정1 — MAE(Maximum Adverse Excursion) 분포
**정의(정확히, 알고리즘은 backtest-agent 재량)**: SHOOT 라벨이 붙은 진입점
t(가격 P_t)마다,
- t_hit = min{ t' ∈ [t, t+60초) : price(t') ≥ P_t×1.03 } (목표 첫 도달 시각 —
  SHOOT 정의상 반드시 존재)
- MAE_pct(t) = ( min{price(t'') : t'' ∈ [t, t_hit]} − P_t ) / P_t (0 이하 값)

전체 SHOOT 모집단에 대해 중앙값/75분위/90분위를 낸다(전체 데이터 사용 —
기술통계라 IS/OOS 분리 불필요, lead 지시 그대로).
**참고 힌트(강제 아님)**: 종목·일자로 정렬 후 정방향 1패스로 "아직 목표 전엔
누적최소가 갱신, 목표 찍는 순간 그 구간 최소가로 MAE 확정"하는 식이면
효율적일 것으로 보인다 — 실제 구현은 backtest-agent가 정한다.

## 2. 측정2 — 노이즈 바닥("-2%가 몇 시그마냐"), 두 갈래로 답한다
**갈래A(로컬 시그마, 주 답)**: 각 SHOOT 진입점 t에서, **진입 이전** 60초
(WINDOW_SECONDS, 재사용) 동안의 틱간 수익률(log return) 표준편차를 그
지점의 "로컬 실현변동성" σ_t로 쓴다(완성된 과거 구간만 사용 — 미래참조
없음). `|-2%| / σ_t`의 중앙값/75/90분위를 보고한다.
**갈래B(대조군 교차검증, 보조)**: CONTROL(오염제거 NEUTRAL) 표본에서
**같은 방식으로** 순방향 60초 내 최대하락폭((price−fwd_low)/price)을
계산해 그 분포에서 **-2%가 몇 번째 백분위인지**를 낸다. -2%가 CONTROL의
"평범한" 구간(예: 50~80분위 근처)에 들어가면 손절이 신호가 아니라 잡음에
자주 걸린다는 뜻이고, CONTROL에서도 극히 드문 크기(95분위+)면 그렇지
않다는 뜻이다.
틱 수익률이 정규분포가 아니라서(두꺼운 꼬리) 갈래A 단독은 오도할 수 있어
갈래B를 같이 낸다 — 새 자유 파라미터 없음(60초·CONTROL 정의 전부 재사용).

## 3. 측정3 — (손절,목표) 격자, IS/OOS 필수 분리
**분할**: IS = 8/04~8/21, OOS = 8/22~8/28(lead 예시 그대로 채택 — 오늘
방향판정 실험의 8/04~8/20 분할과 하루 다르다는 것 인지하고 있으나, 이건
별개 실험이라 그대로 따른다).
**격자(좁게, 기존 실거래 값 근방의 둥근 수만 — 데이터로 고른 값 아님,
정직하게 명시)**:
- 손절 ∈ {-1.5%, -2%(현재값), -3%}
- 목표 ∈ {3%(현재 하위tier), 4%, 5%(현재 상위tier)}
- 3×3=9칸, 보유시간은 60초 고정(LOOKAHEAD_SECONDS 재사용 — 이번 라운드는
  시간척도를 안 바꾼다, 바꿀지 여부는 판정기준 3번이 나온 뒤 판단).
각 칸: 진입 후 손절/목표 중 먼저 닿는 쪽으로 체결, 60초 지나도 둘 다
안 닿으면 그 시점 가격으로 "시간종료" 청산(비용모델은 오늘 CEILING과
동일 값 재사용).
**선택 지표(사전확정)**: IS에서 **거래당 중앙값 실현손익(pct)**이 가장 높은
칸 하나만 고른다(승률·평균 아니고 중앙값 — 소수 큰 값에 덜 흔들리게).
동률이면 현재값(-2%/3%,5%평균)에 가장 가까운 칸을 우선(임의 동률규칙,
정직하게 명시).
**규칙**: 고른 그 칸을 **OOS에서 딱 한 번**만 확인한다. 격자 전체를 OOS로
다시 돌리지 않는다 — 돌리는 순간 이 사전등록이 무효가 된다.
**부가 진단(필수 기재)**: IS·OOS 각각의 **서로 다른 (종목,날짜) 조합 수**를
같이 보고한다 — 틱 건수가 커도 실제 독립 사건 수는 훨씬 작을 수 있다
(오늘 이미 확인된 패턴).

## 4. 판정 기준 — 데이터 보기 전에 확정(lead 문구 그대로, 셋 다)
1. **승자 MAE 중앙값이 -2%보다 깊다** → 손절폭이 원인, 넓히면 개선 여지.
2. **승자 MAE가 얕은데(-1%이내) 손절률이 32.7%(오늘 CEILING 실측값)**
   → 승자·패자가 애초에 다른 집단, 진입 문제로 회귀.
3. **둘 다 아니다** → 이 시간척도(60초/±3%) 자체가 성립 안 함, 척도 변경
   검토 근거로 삼는다.
3번이 나와도 실패가 아니라 이번 측정 목적의 절반이다.

**측정2·3과 판정기준의 관계(명확히)**: 위 세 갈래는 **측정1(+기존 32.7%)만
으로** 정해진다 — 측정2는 "왜 그런지"의 해석 근거(잡음 문제인지 진짜
위험인지), 측정3(격자)은 **1번이 나왔을 때** "얼마나 넓혀야 하고 실제로
나아지는지"를 검증하는 후속 확인이다. 2번·3번이 나오면 격자 결과가 좋게
나와도 그것으로 1번 결론을 뒤집지 않는다(격자만으로는 "같은 집단인지
다른 집단인지"를 못 가른다 — 그건 측정1의 몫).

## 5. 자유 파라미터 정직한 목록
- 모집단을 SHOOT 전체로 잡은 것(25위+1등 대신) — 내 판단, 통계적 검정력
  때문. 데이터 보고 고른 게 아니라 설계 단계에서 미리 정함.
- 격자값(-1.5/-2/-3%, 3/4/5%) — **데이터로 유도 안 됨**, 현재 실거래값
  근방의 둥근 수를 좁게 잡은 것뿐. 정직하게 비유도값으로 표시한다.
- 격자 선택지표(중앙값 실현손익) — 내 판단, 승률/평균 대신 고른 이유는
  명시함. 다른 지표를 썼으면 다른 칸이 뽑힐 수 있다는 것 인정.
- 동률 처리 규칙(현재값에 가까운 쪽) — 임의, 발생 시에만 씀.
- IS/OOS 분할일 — lead 지정값 그대로, 내 선택 아님.
