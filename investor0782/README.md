# 시간대별 투자자 (영웅문 0782)

0782 는 조회를 눌러야 갱신된다. 이쪽은 **1분마다 알아서** 받는다.

```
python investor_flow.py
```

- `.env` 에 `KIWOOM_APPKEY` / `KIWOOM_SECRETKEY`
- 소피증권(`kospi-theme-engine`)과 **독립**이다. 저쪽이 없어도 돈다
- 데이터: `ka10051 업종별투자자순매수` — 한 번 부르면 시장의 업종 전체가 온다
- 기록: `logs/investor.jsonl` (종합만)

## 아는 한계

- **지나간 시간대는 못 받아온다.** REST 에 시장·업종 단위 시간대별 TR 이 없다.
  켠 뒤부터 줄이 쌓이고, 그 전 몫은 첫 줄 누적이 들고 있다
- **매도·매수 두 줄은 못 채운다.** ka10051 은 순매수만 준다
- **지수 선은 아직 없다.** 0782 의 '지수보이기'에 해당하는 것
- 금액 단위 미확정 — 0782 화면 숫자와 대보면 확정된다
