# 리포트 — Opening Range Breakout(ORB) × 시간대정규화 RVOL 상승전조 연구

작성: 2026-09-25/26 · qtai 서브에이전트
사전등록: `results/qtai_orb_rvol_preregistration.md` (결과 보기 **전** 작성, 이후 정의 미변경)
표본: **519종목 × 303거래일** · T0 신호 **183,697건**(ORN 5/15/30 합산, 공식 판정은 ORN=15)

---

## 결론 (사전등록에 미리 정해둔 문장 그대로)

> **"이 조건에서는 비용을 넘는 상승전조 패턴을 찾지 못했다."**

**기각.** 사전등록 §9 기각조건 (a)(b)가 걸렸다 — IS에서 고른 최선 규칙(`RVOL_norm`
상위10%)이 OOS 60분 순수익 **-0.886%**로 (a) 0 이하일 뿐 아니라, (b) **대조군(무조건
진입) 순수익 -0.663%보다도 0.223%p 더 나쁘다.** 이번 연구는 기존의 "신호는 있으나
비용에 못 미친다"보다 **더 약한 결과** — RVOL_norm 상위10% 조건은 이 표본에서
아무 조건 없이 진입하는 것보다도 못했다. ORN 15분(사전등록 공식값) 기준 결론이며,
민감도로 함께 낸 ORN 5분·30분도 전부 순수익 마이너스로 동일한 결론을 지지한다
(ORN=5분만 대조군 대비 근소 우위였으나 그 자체로도 마이너스라 기각조건 (a)에 걸림).

## 3. 핵심 조건과 근거

### 3.1 T0 정의
```
OR 구간 = [09:00, 09:00+ORN)  (ORN = 5/15/30분, 기본 15분)
OR고가 = 그 구간 1분봉 high 최댓값
T0 = OR 종료 이후, 1분봉 종가가 OR고가를 처음 상향 돌파하는 봉의 종료 시각
     (하루·종목당 최초 1회만, 쿨다운 없음 — ORB 원형)
```
- 갭업 제외: 당일 시가가 전일 같은 ORN의 OR고가(없으면 전일종가) 대비 **+3%↑**면
  그 종목·일 제외.
- 60분 라벨을 못 채우는 T0(14:30 이후 돌파)는 신호 자체를 만들지 않음(격자 끝 함정
  차단).
- 사전 필터(MA 정배열 등) **없음** — ORB 원형 그대로.
- 진입가 = 돌파봉 **다음** 봉의 시가(돌파봉 자신의 체결가를 쓰면 낙관적 — 기존 연구의
  교훈을 그대로 적용).

### 3.2 재사용/신규 구현
- **재사용**(import, 복붙 없음): `backtesting.t0_forward_return.round_trip_cost_pct`,
  `krx_tick_size` — 이미 코드베이스 24곳에서 쓰이는 표준 비용함수를 그대로 가져다 씀.
  비용 = 수수료 0.015%×2 + 세금 0.23%(매도1회) + 슬리피지 편도 `max(0.1%, 1틱/가격)`×2.
- **직접 구현**(기존에 없어 새로 작성, 리포트에 명시): ORB 고정 오프닝레인지 T0 탐지,
  RVOL_norm/OR_range_pct 계산, MFE/MAE + ret_h 라벨 — 전부 1분봉 기반이며, 기존
  연구의 틱 기반 유틸(`_precursor_fastpath.to_grid` 등)은 173종목 tick_al 스코프
  전용이라 이번 1,055종목 분봉 스코프에 적용 불가능해 재사용하지 못했다(grep으로
  확인 후 직접 구현 — 사전등록 §2에 이미 명시).

### 3.3 피처
| 피처 | 정의 | 가설 |
|---|---|---|
| **RVOL_norm**(신규 핵심) | T0까지 당일 누적거래량 ÷ 과거 20 유효거래일의 "같은 시각까지 누적거래량" 평균 | 시간대(U자형 계절성) 통제한 상대거래량이 클수록 유리 |
| **OR_range_pct**(신규 보조) | (OR고가−OR저가)/OR시가 | 오프닝레인지가 좁을수록(압축) 돌파가 유의미 |
| `cum_value_today`(대조군) | 09:00~돌파봉까지 누적 거래대금(원) | 기존 연구 재현용(적을수록 유리라는 재현신호 검증) |
| `ret_5min_pre`(대조군) | 돌파봉 종가/5분전 종가−1 | 온셋(이미 상승중) 판정용 |

## 5. 기각조건 판정 (ORN=15분, 공식)

| | 조건 | 판정 |
|---|---|---|
| (a) | OOS 순수익 ≤ 0 | **걸림** — -0.886% |
| (b) | 대조군/무작위 대비 우위 | **걸림** — 대조군 -0.663%, 무작위 -0.657%보다 각각 0.223%p/0.229%p 더 나쁨 |
| (c) | OOS 95% CI가 0 포함 | 문자 그대로는 **통과**([-1.133%,-0.390%]로 0 미포함)이나 **이는 "유의하게 이익"이 아니라 "유의하게 손실"이라는 뜻** — 채택을 뒷받침하는 통과가 아니다 |
| (d) | 온셋격리 후 절반 이하 붕괴 | **해당없음** — 원래 효과가 이미 음수라 "붕괴"를 논할 양의 효과 자체가 없음(참고: 온셋격리 후 -0.610%로 오히려 소폭 개선되나 여전히 대조군보다 나쁨) |
| (e) | 상위 1~2종목 제외 시 결론 반전 | **통과(무의미)** — 상위 1종목(468530) 제외 -0.913%, 2종목(468530, 030530) 제외 -0.934%, 특정 종목 탓이 아니라 전반적으로 나쁨 |
| (f) | 조건 칸 표본 10건 미만 | **통과** — IS 최선 규칙 n=2,806, VAL n=1,281, OOS n=1,068, 전부 최소 10건 상회 |
| (g) | 슬리피지 1.5배 시 부호 반전 | **해당없음** — 원래 순수익이 이미 음수라 비용 증가로 "반전"될 게 없음(참고: 1.5배 적용 시 -0.934%로 더 악화) |

**(a)(b) 두 조건이 명백히 걸려 기각.** (c)는 사전등록 문구상 "통과"로 표시되지만
그 의미가 좋은 신호가 아니라는 점을 반드시 함께 읽어야 한다 — 이 규칙은 "우연히
마이너스"가 아니라 **통계적으로 유의하게 마이너스**다.

## 6. 과적합 위험 평가

- **문턱 선정 과정 자체는 사전등록을 지켰다** — IS에서 8개 후보 전부를 비교해
  최선 1개만 고르고, Validation에서 재계산 없이 그대로 적용, OOS는 1회만 봤다.
  이 과정에서 "결과가 나쁘니 다른 규칙을 다시 골라보자"는 유혹이 실제로 있었지만
  실행하지 않았다(§7 한계에 기록).
- **IS→VAL 방향 유지, VAL→OOS 급격한 악화**(-0.319%→-0.886%)는 전형적인 **국소
  과적합/체제 변화(regime shift)** 패턴이다. IS+VAL(둘 다 방향 유사)로 문턱을
  다시 잡았다면 OOS도 비슷하게 나올지, 아니면 또 다른 체제 변화를 만날지는 이
  데이터로는 답할 수 없다 — **답을 알고 싶다는 유혹이 있었지만 사전등록을 어기지
  않기 위해 시도하지 않았다.**
- **ORN 3개 전부 같은 결론**(순수익 마이너스)이라는 점은 이 실패가 ORN=15라는
  특정 값의 우연이 아니라 **RVOL_norm 상위10% 자체의 구조적 실패**에 가깝다는
  근거다 — 오히려 과적합 위험이 낮은 방향의 증거(넓게 봐도 안 되면 좁게 봐도 우연히
  될 확률도 낮다).
- **RVOL_norm의 실제 판별력(Spearman IC ≈ 0.006~0.018)이 매우 약하다** — IS에서
  상위10% 분위가 "우연히" 조금 나은 것처럼 보인 것(-0.384% vs 대조군 -0.489%)이
  통계적 잡음이었을 가능성을 배제할 수 없다. n=2,806이 작은 표본은 아니지만, IC가
  이렇게 낮으면 분위수 상위/하위 차이도 우연의 범위 안에 있을 수 있다.
- **날짜 클러스터 부트스트랩**을 썼음에도(행 단위가 아니라 거래일 단위로 묶음)
  OOS CI가 [-1.133%, -0.390%]로 폭이 넓다 — 76일 중 신호가 있는 날이 제한적이라
  일자 수 기준 유효표본이 생각보다 적다(day-level n을 명시: OOS 최선규칙은
  실질적으로 수십 거래일 단위로 평균낸 것).

## 7. 한계 (사전등록 §10 + 실행 중 확인된 것)

- 분봉 기반 근사 — `cum_value_today`는 실제 체결 순서를 모르는 `close×volume` 근사
  (틱 데이터 대비 정밀도 낮음).
- 매수/매도 방향(tick rule) 정보가 분봉에는 없어 가격/거래량 피처만 사용.
- RVOL_norm은 과거 20 유효 거래일 평균을 쓰므로 각 종목의 **첫 ~20거래일은 자동
  제외**됨(신규상장 종목 상장 초반이 분석에서 빠짐).
- 519종목은 현재 분봉 데이터가 남아있는 종목 — 상장폐지·장기거래정지 종목 부재
  (생존편향, 기존 연구와 동일한 한계).
- 진입가를 "돌파봉 다음 봉의 시가"로 근사 — 실제 체결은 그 1분 구간 어디서든
  발생할 수 있어 약간의 낙관/비관 편향이 남을 수 있음(방향은 사전에 알 수 없음).
- **정직하게 기록하는 유혹들** (사전등록 §0 서명대로, 코드는 바꾸지 않고 여기 기록):
  1. OOS 결과를 본 뒤 "IS+VAL을 합쳐 문턱을 다시 잡으면 어떨까"라는 생각이
     들었다 — **시도하지 않았다.**
  2. `or_range_pct`(IS -0.463%)가 `rvol_norm`(IS -0.384%)과 근소한 차이라
     "혹시 OOS에서는 or_range_pct가 더 잘 나오지 않을까" 궁금했다 — **§6-3의
     절차(선정 후 재선택 금지)를 지켜 확인하지 않았다.** (참고로 IS 격차
     0.079%p는 기존 연구가 경계한 "0.009 AUC 차이로 축을 잘못 고른" 사례와 유사한
     규모라, 애초에 확인해도 신뢰할 근거가 못 됐을 것이다.)
  3. ORN=5분이 대조군을 근소하게 이겼다는 것을 보고 "ORN=5를 공식으로 했으면
     좋았겠다"는 생각이 들었다 — 이것이 바로 사전등록 §6-5가 원천 차단하려던
     사후 ORN 재선택이라 **판정을 바꾸지 않았다.**
  4. RVOL_norm의 극단값(최대 1,971배)이 결과를 왜곡했을 가능성을 승자독식으로
     확인하고 싶었으나, 이는 사전등록에 없는 추가 필터라 **시도하지 않고 여기에만
     의문으로 남긴다**(다음 실험 제안에 포함).

## 8. 다음 실험 제안

1. **RVOL_norm의 극단치 처리**: 최댓값이 평균의 수백~수천 배(예: 1,971배)로,
   분포가 매우 두꺼운 꼬리를 가진다. 상위10% 분위 안에서도 극단치 소수가 평균을
   왜곡했을 가능성이 있다 — winsorize 또는 로그변환한 RVOL_norm으로 **새로운
   사전등록**을 통해 재검증할 가치가 있다(단, 이번 결과를 "고쳐서 되게" 만드는
   시도가 아니라 독립된 가설로).
2. **IS→VAL은 방향 유지, VAL→OOS만 급변**한 패턴 자체가 흥미로운 신호다 — 이
   시기 구분(2026-06-08 이후)에 시장 전체 레짐이 바뀌었는지(지수 변동성, 전체
   ORB 성공률의 시계열 등) 별도로 조사하면 "왜 실패했는지"에 대한 설명력을 높일
   수 있다.
3. **or_range_pct의 부호 있는 활용**: 이번엔 상위/하위 10% 분위로만 봤는데, IC가
   음수(-0.075)로 나온 것은 "좁을수록 유리"라는 원래 가설과 방향이 맞다 — 분위
   대신 연속값으로 회귀분석하거나, RVOL_norm과의 상호작용(둘 다 조건 충족)을
   보는 것은 검토 가치가 있다(새 사전등록 필요).
4. **cum_value_today 방향 반전의 재확인**: 기존 롤링 T0 연구의 최상위 재현신호가
   ORB T0에서는 사라졌다(오히려 근소하게 반대). 이것이 "신호정의 의존적"이라는
   결론을 강화하는지, 단순 표본잡음인지 후속 연구로 확인할 가치가 있다.
5. 이번 결과가 대조군보다도 나쁘다는 점에서, **ORB × RVOL_norm 조합 자체를 더
   파는 것은 권하지 않는다** — 기존 연구의 결론("같은 틀로 더 파는 것은 권하지
   않는다")과 마찬가지로, 다른 T0 원형(예: 거래대금 급증 자체를 T0로 삼는 등)을
   시도하는 편이 나을 것으로 판단한다.
