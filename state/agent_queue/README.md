# 작업 큐

에이전트가 지금 일을 끝내면 **스스로 다음 항목을 꺼내 간다.** 사람이 매번 다음 지시를
넣지 않아도 이어서 돈다.

`state/agent_queue/<agent>.md` 에 체크리스트로 적는다:

    - [ ] 할 일
    - [~] 지금 하는 중 (에이전트가 직접 표시)
    - [>] 선행 결과 대기 — 지금은 못 뽑는다 (에이전트가 직접 표시)
    - [x] 끝남

## 에이전트 규칙
1. 작업이 끝나면 자기 큐 파일을 열어 위에서부터 첫 `- [ ]` 를 가져간다.
2. `- [~]` 로 바꾸고 시작한다. 끝나면 `- [x]` 로 바꾸고 보고한다.
3. 큐가 비면 유휴라고 보고한다 — 임의로 일을 만들어내지 않는다.
4. 항목이 모호하거나 위험하면 하지 말고 lead 에 물어본다.
5. 순서를 바꾸지 않는다. 위에서부터다.
6. 선행 결과를 기다려야 해서 지금 못 하는 항목은 `- [>]` 로 바꾼다. agent-poke 가
   `- [ ]` 만 세므로, 안 바꾸면 못 하는 일로 30분마다 계속 깨워진다.
   선행 결과가 도착하면 다시 `- [ ]` 로 되돌린다.

## 넣는 쪽 규칙 (lead / 다른 에이전트)
- 한 항목은 한 작업이다. "A 하고 B 하고 C" 는 세 줄로 나눈다.
- 판단이 필요한 것은 큐에 넣지 않는다. 큐는 이미 결정된 일만 담는다.
- 앞 항목의 결과에 따라 달라지는 일은 넣지 말고, 결과를 보고 그때 넣는다.
