      (O_CREAT|O_EXCL 획득과 LOCK_STALE_SECONDS 회수 사이 틈: A가 stale 판정 후
      remove 하는 사이 B가 새 락을 잡으면 A가 B의 락을 지우는가). 판정 불가면
      불가라고 하고 실거래 전 남은 위험으로 기록.

      통합할지 판단하고 근거를 대라. 자동 일일손실 킬스위치는 이미 계좌 통합됨.
- [x] 주간/월간 손실 한도가 설계엔 있으나 미구현이라고 했다 — 필요한지 판단하고,
      필요하면 권장값을 제안만 해라. 값 적용은 사용자 승인 후.
- [x] 실거래 켜기 전 리스크 체크리스트를 한 장으로 정리 — 무엇이 강제되고 무엇이
      아직 null 이고 무엇이 미검증인지. state/agent_reports/ 에 남겨라.
