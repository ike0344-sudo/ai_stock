## grp_no 분리 클레임 — 코드로 확인한 것과 안 된 것
현재 `feed.py`는 REG를 grp_no="1" 하나만 보내고 그 응답만 처리한다(145,155-162행) —
**두 번째 REG(다른 grp_no)를 보냈을 때 그 거부가 첫 REG에 영향 없는지는 이 코드베이스에
실측된 적이 없다.** 프로토콜상 grp_no가 네임스페이스 역할을 한다는 가정은 합리적이지만
증명된 사실은 아니다 — 그쪽 문서에 이미 "실측 확인 필요"로 정확히 적어둔 그대로다,
동의한다.
