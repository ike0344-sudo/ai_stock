# [lead] 분봉 통합본을 ai_stock 에서도 쓰게 해라 — 규칙만 걸고 수단을 안 준 건 내 잘못이다

"무조건 통합(AL)"을 상시 규칙으로 걸었는데, **분봉은 통합본이 ai_stock 쪽에 없다.**
백테스트 코드는 전부 `data/stocks/minute`(KRX 전용 1,046종목)를 본다.

그래서 오늘 실제로 사고가 났다 — backtest-agent 가 "대금 1등 관성"을 재다가
KRX 분봉으로 계산했고, AL 원틱과 대조하니 **오차 1.1~1.3%p** 로 측정하려던 신호
크기(-0.5~-0.8%)와 같은 자릿수라 **판정보류**로 끝났다
(`backtest-agent_20260901-153000_chgtop_leader_persistence.md`).

## 있는 것
`kospi-theme-engine/data/cache/minute_al/` — **1,267종목, 1.7GB**.
형식은 KRX 분봉과 **동일**하다(`date,open,high,low,close,volume`, 예: `2026-03-20 09:48:00`).
lead 가 직접 열어 확인했다.

## 할 일
**1.7GB 를 복사하지 마라.** 경로만 바라보게 한다.

`backtesting/minute_store.py`(신규, 작게) 를 만들어라 — `daily_cache.py` 와 같은 결이다:
- 통합 분봉 디렉터리를 돌려주는 함수 하나. 없으면 **에러를 내라**(조용히 KRX 로 떨어지지 마라 —
  그게 오늘 사고의 원인이다).
- 기존 코드가 `os.path.join(data_dir, "stocks", "minute")` 로 경로를 만드는 곳이 많다.
  전부 뜯어고치지 말고, **일단 이 함수만 만들고 어디를 바꿔야 하는지 목록으로 보고해라.**
  실제 교체는 내 승인 뒤에 한다(`backtesting/*.py` 수정은 lead 허락 규칙).

## 먼저 확인해서 보고할 것 (교체 전에 알아야 한다)
1. **기간** — AL 분봉이 언제부터 언제까지인가. KRX 분봉(1,046종목)과 겹치는 기간은?
   AL 이 더 짧으면 과거를 보는 연구는 못 옮긴다.
2. **종목** — 1,267 vs 1,046. AL 에만 있는 종목 / KRX 에만 있는 종목 각각 몇 개인가.
3. **결측** — 거래일 누락이 있는가.
4. **값 차이** — 같은 종목·같은 시각에서 KRX 와 AL 이 얼마나 다른가.
   backtest-agent 가 잰 1.1~1.3%p 를 네 방식으로 독립 재확인해라(그대로 믿지 마라).
   차이가 큰 종목/시간대에 패턴이 있는지도 봐라(대형주는 작고 소형주는 큰가 등).

- 소피증권이 장중에 이 디렉터리를 쓰고 있을 수 있다. 대량 읽기가 부딪히지 않게 살펴라.
