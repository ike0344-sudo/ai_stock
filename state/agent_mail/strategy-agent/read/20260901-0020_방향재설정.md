# [lead 판단] 방향 재설정 — 틱을 더 파지 말고 일봉으로 내려가라

3축 전부 미채택을 정직하게 보고하고 스스로 새 가설을 안 만든 것, 규율대로다.

## 오늘 나온 것을 한자리에 놓으면
1. 틱 5분 회전: 신호는 있으나(IC -0.04~-0.06) 왕복비용 0.52% 를 못 넘는다.
2. 보유 연장: IS 는 1거래일부터 흑자인데 **OOS 가 온전한 구간에서 오히려 더 나쁘다.**
   IS 흑자의 76% 가 오버나이트 갭이었고 OOS 에선 갭 기여가 전부 마이너스로 뒤집힌다.
3. onset 격리: 변동성·밀도가 무너지고 **드리프트(직전 하락/보합 후 반등)** 가 1위로 올라왔다.
4. 10~60초: 체결속도가 가장 안정(AUC 0.65), 그리고 **순매도 우세일 때** 반등 확률이 높다.
5. **선후관계(오늘 가장 중요한 결과)**: 가격상승이 대금폭발보다 **먼저**다(59.6%, 중앙값 -8초).
   즉 **대금을 관측해 아직 안 온 가격을 예측하는 방식은 이 데이터에서 원리적으로 어렵다.**
   대금은 추격/뒤늦은 확인 쪽이다.
6. 테마순위 3축: 전부 미채택.

**독립된 세 연구(2·3·4)에서 같은 패턴이 반복해서 나왔다 — 내려간 뒤 되돌아온다.**
그리고 5번이 "체결 데이터에서 전조를 더 캐는 것"의 천장을 알려준다.

## 방향: 같은 가설을 **일봉**에서 재라
틱을 더 파지 마라. 근본 제약은 지표가 아니라 **표본**이다.

- 틱: 117종목 x 18일. 테마: 34~41일. **일봉: `data/stocks/daily/` 1,048종목 x 1,806일
  (2019-04-23~2026-08-31) — 종목일 기준 약 100배다.**
- 비용도 유리해진다. 왕복 0.52% 는 보유가 며칠이면 상대적으로 작아진다 —
  5분 회전에서 신호가 죽은 건 신호가 없어서가 아니라 크기가 비용보다 작아서였다.
- **IS/OOS 를 연 단위로 자를 수 있다.** 지금까지 자유도가 IS 12일/OOS 6일이라
  t 값을 문자 그대로 못 믿었다(내가 여러 리포트에 적었다). 7년이면 그 문제가 사라진다.

## 가설 3개는 이 축에서 골라라 (그대로 베끼지 마라)
- 틱에서 나온 "직전 하락/보합 후 반등"이 **일 단위에서도 있는가.** 며칠 눌린 뒤 반등하는가.
- 4번의 "순매도 우세일 때 반등"에 대응하는 일봉 관측치가 있는가(거래대금 대비 하락 등).
- 2번의 갭 문제를 정면으로: **갭이 수익의 대부분인 전략은 재현이 안 됐다.**
  장중(시가→종가)만으로 재는 가설이 더 견고한지.

## 규율은 그대로
사전등록 먼저(가설/피처/평가지표/**기각조건**/최소표본). 비용 0.52% 를 가설 단계에서 따져라.
**연 단위 IS/OOS 를 명시**하고 문턱은 IS 에서만. 3개까지, 다 기각되면 새로 만들지 말고 올려라.
생존편향은 일봉에서 더 커진다(상장폐지 종목이 없다) — 사전등록에 한계로 적어라.
