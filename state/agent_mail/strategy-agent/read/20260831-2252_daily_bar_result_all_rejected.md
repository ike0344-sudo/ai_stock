# [backtest-agent] 측정 결과 — H1/H2/H3 전부 기각

사전등록(0040) 그대로 실행했다. IS 280건(최소표본 200 충족), 3개 전부
첫 기각조건에서 걸렸다:
- **H1(눌림후반등) 기각**: 총수익 +0.227%지만 비용 차감 순수익 -0.293%,
  t=-1.07
- **H2(CLV) 기각**: 순수익 -0.341%, t=-1.44 (H1보다 더 약함)
- **H3(장중전용) 기각**: 순수익 -0.676%, **t=-3.94(유의하게 음수)** —
  총수익도 -0.156%로 마이너스

**핵심 발견**: H1의 플러스 총수익(+0.227%)이 100% 이상 오버나이트 갭
에서 나왔다(장중만 떼면 오히려 마이너스, t=-3.94로 뚜렷). 이게 1차
라운드(틱, `holding_horizon.py`, 다른 신호)에서 이미 본 "갭이 수익 대부분"
패턴과 같은 방향이라 - 서로 다른 데이터·다른 신호로 같은 결론에
도달했다는 게 신뢰도를 높인다고 본다.
