# 호가 재도전 사전등록 독립 교차검증 (2026-08-30)

사용자가 각자 판단을 파일로 내라고 지시한 항목(데이터량/피처/기준/그동안
할 일) — strategy-agent가 이미 `docs/ORDERBOOK_DIRECTION_PREREGISTRATION.md`
로 제출했다. 처음부터 다시 만들지 않고, 숫자 검증 위주로 독립 교차검증한다.

## 1. 최소 데이터량 계산 — 검증함, 맞다
"로지스틱 날짜별 SD≈5.2~5.7%p" 주장을 내 원본 데이터(stage2 전체표본
로지스틱 날짜별 정확도 53.77/50.30/52.42/65.31/61.11/58.57%)로 직접
재계산했다: **표본SD(ddof=1)=5.74%p, 모집단SD=5.24%p** — 주장한 범위와
정확히 일치. SE=SD/√n 표(n=6→2.25%p, n=8→1.94%p, n=14→1.47%p, n=20→
1.23%p)도 재계산해서 전부 일치 확인. **45~50거래일(2-fold)/60~65거래일
(3-fold) 권장에 동의한다** — 별도 계산 안 하고 이 결론을 그대로 받는다.

## 2. 피처 4개 — 동의, 추가 제안 없음
Lee-Ready·벽두께변화·스프레드·호가불균형 4개는 `ORDERBOOK_CAPTURE_DESIGN.md`
가 확정한 10단 호가 스키마로 전부 계산 가능하다(직접 스키마 대조 확인).
새 피처 추가 제안 없음 — 기존 6개 신뢰피처 유지 방침도 동의.

## 3. 발견 — 두 사전등록 문서 간 숫자 불일치 (수정 요청)
`docs/TOP25_RANK1_DIRECTION_PREREGISTRATION.md`는 상호검증 후
recall(CRASH)≥40%/precision(SHOOT)≥55%로 통일됐는데(strategy-agent_
20260830-222800), **`docs/ORDERBOOK_DIRECTION_PREREGISTRATION.md` §4는
아직 이전 값(recall(CRASH)≥50%/precision(SHOOT)≥60%)이다.** 같은 비용모델
(TIERS 4%/손절2%/왕복비용0.36%)에서 나온 두 문서가 다른 숫자를 쓰는 건
일관성 문제로 보인다 — 의도적으로 호가 재도전엔 더 엄격한 기준을 쓰려는
것이라면 그 이유를 문서에 명시해달라, 아니면 40%/55%로 맞추는 걸 제안한다
(내가 직접 고치지 않음 — docs/ 문서는 그쪽이 작성한 것이라 요청만 한다).
