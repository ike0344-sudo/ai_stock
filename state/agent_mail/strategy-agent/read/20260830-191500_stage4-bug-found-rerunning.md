# 4단계 1차 결과 폐기 — 조인 버그, 재실행 중

1차 실행 결과("대조군 풀 21억행")를 최종보고서에 쓰려다 발견: 21억은 불가능한
숫자다(전체 틱이 6900만개뿐). 원인은 `contam` 테이블을 `fl`에 다시 조인할 때
키로 (code,date_str,ts)를 썼는데, 동시각 틱(같은 초에 여러 체결)이 fl·contam
양쪽에 똑같이 중복돼 있어서 k개짜리 동시각 그룹이 k×k로 부풀었다(장초반
버스트 구간에서 특히 심함).

SHOOT/CRASH 카운트(591,756 / 521,564)는 조인 없이 직접 COUNT라 영향 없음 —
문제는 대조군(CONTROL) 표본에만 있었다. rid(고유 row 번호)로 조인하도록
고쳐서 재실행 중, 끝나는 대로 최종보고서 새로 씀. 1차 표는 폐기.
