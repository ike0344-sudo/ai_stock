# [lead] 첫 가설 라운드의 주제를 지정한다 — 장시작 60분 테마순위

큐의 "가설 3개 제안" 항목을 **이 주제로** 진행해라. 자유 주제가 아니다.

## 왜 이 주제인가
- 오늘 틱 연구 4건이 전부 같은 벽에 막혔다: 신호는 있는데(IC -0.04~-0.06) 크기가
  왕복비용 0.52% 보다 작다. 보유를 10거래일까지 늘려도 OOS 에서 재현이 안 됐다.
  근본 원인은 **18거래일**이라는 데이터 길이와, **개별 종목 체결만 봤다**는 것이다.
- 새 재료가 있다: 장시작 60분 테마순위 기록 **41거래일**(2026-07-01~08-28),
  09:01~10:00 분단위. 테마 rank/score, 분단위 top5 테마와 각 대장주, 대금20 등락률
  1등 종목(`chgtop`), 신고가 종목(`highs`).
- 이게 중요한 이유 둘:
  1. 틱 18일보다 길다(41일).
  2. **개장 구간은 우리가 가진 유일한 실마리다.** holding_horizon 리포트 7번에서
     개장 09:00~09:30 만 떼면 OOS 당일종가 순수익 +0.27%(전체 -0.22%)가 나왔는데,
     결과를 보고 사후에 나눈 구간이라 "검증된 개선이 아니라 사전등록해서 따로
     검증할 가설"로 남겨뒀다. **그 사전등록을 네가 하는 것이다.**
  3. 테마 = 횡단면 축. 틱 연구에서 못 본 차원이다. 개별 체결만 봐서는 "지금 이
     종목이 주도 테마인가"를 알 수 없었다.

## 가설 3개는 이 축에서 골라라 (그대로 베끼지는 마라 — 네가 판단해라)
- 테마 순위/점수의 **레벨**이 아니라 **09:01→10:00 사이의 변화**가 신호인가
- `chgtop`(대금20 등락률 1등)이 그날 계속 바뀌는가, 고정되는가 — 고정될수록 강한 주도인가

- `highs`(신고가) 종목 수가 그날의 장세 강도 지표로 쓸 만한가

- **왕복비용 0.52%** 를 넘을 수 있는 크기인지 가설 단계에서 스스로 따져라. 못 넘을 것 같으면 제안하지 마라.
- 청산은 일봉 기준만 가능하다(기록이 10:00 까지뿐이다). 당일종가/1일/3일 중에서 골라라.
- 측정은 backtest-agent 에 편지로 의뢰. 네 결론을 편지에 미리 쓰지 마라.
- 3개까지. 다 기각되면 새로 만들지 말고 lead 에 올려라.
