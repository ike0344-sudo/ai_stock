# 두 결과 확인·검산 완료 — 탈환 완화는 보류 권고, 오늘 틱실험은 여기서 멈추자

CEILING·TAKEOVER 둘 다 검산했다(청산사유 합계, 일별수익률 합산, burst
비율 교차검증 — 전부 일치). 좋은 작업이다, 특히 3.5시간 정체를
사후분석까지 남기고 62.5초로 고친 것과 사전등록 정지규칙(n=3, n=1)을
스스로 지켜서 판정보류로 멈춘 것 둘 다 잘했다.

**CEILING에서 제일 중요하게 본 발견**: 방향 100% 맞춰도 손절(32.7%)이
익절(28.8%)보다 많다는 것 — 이건 방향예측(호가 포함) 문제가 아니라
진입타이밍/청산설계 문제다. 오늘 종일 물었던 "호가 투자할 값어치"
질문에 새로운 축을 하나 더한 셈이다(지금 당장 손대자는 건 아니고
기록만).

**탈환 정의완화는 지금 보류를 권한다** — burst_detected(0.43%)가
SHOOT(3.37%)·CRASH(4.84%)보다 훨씬 낮다는 게 표본부족이 아니라
"탈환 자체가 활동성 관점에서도 NEUTRAL에 가깝다"는 두 번째 독립신호로
보이고, 오늘 이미 6개 실험을 돌려서 여기서 새 조건을 계속 열면 개별
실험은 깨끗해도 전체적으로 다중비교 위험이 쌓인다.

**제안**: 오늘 틱기반 실험은 여기서 멈추자. 지금까지 결과가 일관되게
"틱만으로는 방향이 약하다·부분조건도 안 나아진다·burst탐지는 되지만
방향모름·완벽한 방향이어도 청산설계 한계로 상한 작음·탈환도 NEUTRAL에
가까움" 쪽으로 수렴한다 — 호가 사전등록(45~65거래일) 기다리는 게
맞다고 본다. 그 사이엔 ORDERBOOK 문서 §6의 새 피처 함수 합성데이터
자체점검 쪽으로 넘어가는 걸 제안한다.
