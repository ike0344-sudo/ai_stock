# 거래대금25위+등락률1등 부분집합 방향판정 재시험 — 사전등록 완료, 실행 요청

사용자 승인받은 실험이다. 사전등록: `docs/TOP25_RANK1_DIRECTION_PREREGISTRATION.md`
(실행 전 반드시 읽어라 — 판정불가 처리 조건 포함).

## 1단계 — 먼저 표본 개수만 세서 보고해라 (모델링 전에)
조건: 매 시점 t에서 (a) 장중 누적거래대금 25위 이내, **그리고** (b) 그
25종목 중 시점 t 등락률(시가대비) 1등. 틱으로 정확히 계산(분봉 근사 아님).
SHOOT/CRASH 라벨 전체(591,756/521,564)에 이 필터를 적용한 결과 개수를
먼저 보고해라.

**게이트(사전등록, 미달이면 그 자리에서 멈추고 "판정불가"로 보고, 억지로
모델 안 돌림)**:
- 검증구간(8/21~8/28) 전체 ≥1,000건 그리고 SHOOT·CRASH 각 ≥200건
- 학습구간(8/04~8/20) 전체 ≥2,000건 그리고 각 클래스 ≥400건
둘 다 충족해야 2단계로 넘어간다.

## 2단계 — 통과하면 실행 (조건 하나만 다르게, 나머지 전부 동일)
시간분할(8/04~8/20 학습/8/21~8/28 검증), 모델(로지스틱+트리 depth=3, 튜닝
없음), 피처(6개 신뢰피처) — 전체표본 시험과 완전히 동일하게, 이번 필터만
추가.

**측정**: 정확도, 혼동행렬, recall(CRASH)/precision(SHOOT), ROC-AUC,
날짜별 정확도(전체표본 시험과 동일 형식). **추가로 필수**: 검증구간에
포함된 서로 다른 (종목,날짜) 조합 개수 — 15개 미만이면 결과가 좋아도
"일화적, 통계적 결론 불가"로 같이 표기해라(사전등록 §3).

**기준**: 이 부분집합의 검증구간 실제 다수클래스 비율(전체표본 49.66%와
다를 수 있음, 필터링 후 재계산) + 5%p, 날짜별 과반 통과. CRASH recall≥50%,
precision(SHOOT)≥60%(둘 다 손익구조에서 유도된 기존값 재사용, 새로 안
만듦).

## 보고
전체표본 결과(55.19%/54.93%)와 **나란히** 표로 내고, 좋아졌다면 표본축소로
인한 우연 가능성(위 (종목,날짜) 조합수, 클러스터링으로 실제분산이 이론치보다
크다는 점)을 반드시 같이 논해줘.

**미리 못박아둔 것**: 이 결과가 통과선을 넘어도 그 자체로 채택 근거가
아니다 — 8월은 이미 연 홀드아웃이라 재현 확인이 불가능하다. 호가 데이터
재도전 때 이 조건도 같이 볼지 정하는 참고자료로만 쓴다. 보고서에 이
문장 그대로 남겨줘(결과 보고 빼는 일 없게).
