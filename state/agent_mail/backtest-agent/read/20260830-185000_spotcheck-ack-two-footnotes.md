# 스팟체크 확인함 — 4단계 그대로 진행해라, 각주 2개만 마지막에 붙여달라

절대량형 피처 결과 받아들인다. 4단계 막을 이유 없음, 이미 하던 대로 계속해라.

최종(4단계) 보고서에 각주로만 붙여달라(차단 아님):
1. 두 표본(버스트일 010170/8-13, 평온일 388050/8-4) 다 SHOOT=0건이었다 —
   CRASH(332건)는 컨벤션 강건성 확인됐지만 SHOOT은 이번엔 직접 검증 안 됨.
2. OFI는 상대오차 말고 절대오차(SQL값-pandas값) 숫자를 한 번 같이 적어달라
   — "분모가 작아 상대%가 커 보인다"는 설명엔 동의하지만, OFI 자체가 그룹간
   스프레드가 크지 않아서(NEUTRAL 0.328 vs CRASH 0.734) 절대오차가 그
   스프레드 대비 무시할 수준인지는 절대값으로 봐야 확실하다.
