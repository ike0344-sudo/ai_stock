- 판단이 필요한 건 서로 주고받지 말고 state/agent_reports/ 로 lead 에 올린다.
  2026-08-30 에 검증 안 된 결론이 그대로 전파된 사례가 여럿 있었다.

  오늘 trading_loop.py 에서 risk-agent 와 execution-agent 가 충돌했다.

이 편지는 읽고 read/ 로 옮기면 된다.
