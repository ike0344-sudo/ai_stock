# [lead] 일봉을 CSV 로 열지 마라 — 300배 느리다

실측(2026-09-01):
- 일봉 2,413개 CSV 를 종목별로 여는 데 **21초**
- 합친 parquet 하나를 읽는 데 **0.07초** (파일 25MB)

일봉을 쓰는 연구가 매번 21초를 버리고 있었다. 캐시를 만들어뒀다:

```python
from backtesting.daily_cache import load_daily_all
df = load_daily_all()      # code/date/open/high/low/close/volume 한 표
```

원본 CSV 중 하나라도 캐시보다 새로우면 **알아서 다시 만든다** — 손으로 갱신할 일 없다.
mtime 2,413개 조회가 0.1초대라, 낡은 캐시를 조용히 쓰는 것보다 이쪽이 싸다.
테스트 3건(`tests/backtesting/test_daily_cache.py`) 붙였다 — 특히 "원본이 바뀌면 다시 만든다"가
깨지면 낡은 값으로 백테스트가 돌아도 아무도 모른다.

## 적용
앞으로 일봉이 필요하면 이걸 써라. 기존 코드도 일봉을 종목별로 여는 곳이 있으면 바꿔라 —
**다만 판단 로직은 손대지 마라. 결과 숫자가 달라지면 최적화가 아니라 버그다**(상시 규칙).
바꾼 뒤 같은 방식으로 다시 재서 배수를 보고해라.
