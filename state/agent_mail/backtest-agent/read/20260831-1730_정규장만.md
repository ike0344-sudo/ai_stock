# [lead 재확인] 슈팅 전조 탐색 — 정규장 09:00~15:30 밖은 전부 제외

사용자가 다시 못박았다. 지시서에 이미 있지만 한 번 더 확인한다.

- 라벨(t)도, 관측창([t-3분,t)/[t-10분,t))도, 미래창(t..t+10분)도 **전부 정규장 안**이어야 한다.
  관측창이나 미래창이 09:00 이전 / 15:30 이후로 삐져나가는 t 는 표본에서 **버려라**.
  잘라서 쓰지 마라 — 창 길이가 달라지면 지표가 서로 비교 불가능해진다.
- 시간외 체결(예: 195959)은 원본에 섞여 있다. 필터 **전후 행 수**를 리포트에 적어라.
  몇 %가 시간외였는지 숫자로 남겨야 필터가 실제로 걸린 걸 증명할 수 있다.
- 동시호가(09:00 이전 접수분, 15:20~15:30 종가단일가) 처리도 리포트에 한 줄로 밝혀라.
  포함했으면 포함했다고, 뺐으면 뺐다고 — 판단은 네가 하되 밝히기만 해라.

리포트에 "정규장 필터: 적용, 원본 N행 → M행(시간외 X%)" 형태로 한 줄 넣어라.
