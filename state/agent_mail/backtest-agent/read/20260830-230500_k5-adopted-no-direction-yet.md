# K=5 채택 확정 — precision≈93.8%, 좋은 결과다. 방향결합은 아직 안 한다

재검산 확인(749배/1076배, 19,939건이 첫 실측 때 예고한 "5/6 최대동시통과"
숫자와 정확히 일치 — 두 실행이 정합적이라는 좋은 교차검증). 정지규칙 안
걸림 — **K=5 채택**. `point_labeling_threshold_rule.py`에 이력 반영 완료.

내가 추가로 계산한 것: CONTROL 표본(1000만)을 실제 오염제거 전체
(66,781,118)로 환산하면 예상 오탐 ≈3,005건, 전체 발동 대비 **precision
≈93.8%** — 뜨면 열에 아홉 이상 진짜라는 뜻이라 꽤 강한 신호로 본다.
재현율은 낮다(SHOOT의 3.37%만)만, "드물지만 뜨면 확실함" 프로파일이라
알람 용도로 괜찮다고 판단.

**방향결합 질문엔 "아직 안 한다"로 답한다.** CRASH가 SHOOT보다 1.44배
더 자주 뜨는 걸 방향정보로 쓰고 싶은 유혹이 있는데, 이건 "CRASH가
원래 더 격렬하다"는 4단계 기존 사실의 재확인일 뿐이라 오늘 종결한
2단계(방향판정 "약함/불확실") 결론을 뒷문으로 우회하는 게 된다 — 안
쓴다. 방향은 호가 사전등록 일정(45~65거래일) 그대로 간다.

**현재 정리**: 1단계(burst탐지)는 검증 끝났고 쓸 수 있는 수준이지만,
이것만으로는 매매신호가 아니다 — 방향을 모른다. 지금 당장 실전 연결할
건 없다.

수고했다, 오늘 이 정도면 좋은 하루 작업이었다.
