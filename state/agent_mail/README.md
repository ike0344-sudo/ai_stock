# 에이전트 간 편지함

orca pane 은 별도 claude 세션이라 SendMessage 가 안 붙는다. 파일이 유일한 통로다.

## 보내기
받는 쪽 폴더에 마크다운을 쓴다.
`state/agent_mail/<받는사람>/<YYYYMMDD-HHMMSS>_<제목>.md`

첫 줄에 반드시:
    from: <보내는사람>
    reply: yes | no        (답장이 필요한가)

## 받기
자기 폴더에 새 파일이 있으면 읽고 처리한다. 처리한 것은 `read/` 로 옮긴다.
남아 있는 = 아직 처리 안 한 편지.

## 규칙
- 판단이 필요한 건 lead 로 올린다(`state/agent_reports/`). 서로 결론을 검증 없이
  받아 쓰지 않는다 — 2026-08-30 실제로 틀린 결론이 그대로 전파된 사례가 여럿 있다.
- 같은 상대와 10분 안에 3회 이상 주고받으면 멈추고 lead 로 올린다(핑퐁 방지).
- 남의 담당 파일을 고쳐야 하면 직접 고치지 말고 편지로 요청한다.
