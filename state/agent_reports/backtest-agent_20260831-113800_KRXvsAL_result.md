## 3. 판단
1. **CEILING**: 통합데이터에서도 방향은 안 바뀌지만(플러스 유지) 규모는
   절반으로 줄고 손절비율은 더 나빠졌다 — "완벽한 방향에도 청산설계가
   발목잡는다"는 결론이 강화됐다. 이건 NXT가 붙어서 손해라기보다,
   **표본이 106/117로 줄어서(11종목 결측) 기회 자체가 준 영향과 섞여
   있어 순수하게 NXT 효과라고 단정 못 한다** — 11종목이 채워지면 재확인
   필요(§4).
2. **TAKEOVER**: "탈환이 방향정보를 담는다"는 가설은 이번 재측정으로
   **더 약해졌다** — 표본이 늘었는데 방향신호는 사라졌다. 두 실험팔
   전부 여전히(오히려 더) 계산 불가능한 수준.
3. **strategy-agent의 "오늘 틱실험 중단" 권고는 이번 건에 해당 안 됨**
   (lead 지시대로) — 새 가설이 아니라 기존 결론이 KRX 반쪽 데이터였다는
   걸 확인하는 재측정이었고, 다중비교 위험을 새로 안 늘렸다.
