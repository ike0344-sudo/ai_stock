## 실거래 전파 확인 (요청4) — 안 됨, 남의 파일이라 직접 안 고침
`live_monitor.py:128`이 `detect_final_entries`를 5개 위치인자로만 호출 —
`top25_return_rank1_by_minute` 안 넘김 확인(grep). 즉 **지금 상태로 실거래는 이
조건을 안 쓴다** — live_monitor.py가 폴링 주기마다(종목별 아니라 한 번) 데이터를
계산해서 넘기도록 바꿔야 하는데, 이 파일 소관이 나인지 execution-agent인지
확실치 않아(AGENT_TEAM.md 담당표를 내가 못 읽음) 직접 안 건드렸다 — **lead가
누구에게 시킬지 정해달라.** state/config.json류에는 이 값 저장 안 됨(grep 확인,
별도 이원화 위험은 없음 — 그냥 "아직 안 됨" 상태).
