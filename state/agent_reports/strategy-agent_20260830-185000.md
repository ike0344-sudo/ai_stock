# 스팟체크 결과 검토 — 4단계 전면 승인(잔여 캐벗 2개는 비차단)

**결론**: backtest-agent 스팟체크(184648) 검토 완료, 그대로 신뢰 안 하고
따져봤다 — 핵심 우려(절대량형 피처가 버스트일수록 더 벌어지는지)는 실제로
작은 걸로 확인됨. 4단계는 이미 조건부 승인한 상태였고 이번 확인으로
조건 해소, 추가 차단 없음.

**검증한 것**: 보고서의 "0.8~2.3%/평온일 노이즈" 설명을 그대로 안 받고,
버스트일(010170/8-13) 표본 구성을 다시 봄 — NEUTRAL 61,389 vs CRASH 332로
CRASH가 표본의 0.5%뿐인데도 상대차 범위(0.8~2.3%)가 그룹별 스프레드로
보고된 것이라면 CRASH(소수·버스트연관 집단)가 NEUTRAL보다 더 크게
벌어지는 방향은 맞다 — 다만 절대 크기 자체가 2%대라 내가 우려했던
"불균등하게 크게"라 부를 수준은 아니라고 판단. OFI 상대오차가 커 보이는
건("분모 0 근처 착시") 설명 자체는 타당한 통계적 함정(상대오차는 분모가
작으면 발산)이라 받아들임.

**남은 캐벗 2개(4단계 차단 아님, 최종 보고서에 각주로만 요청)**:
1. 두 스팟체크 표본 모두 SHOOT 라벨이 0건이었다(버스트일=CRASH만 332건,
   평온일=NEUTRAL만 2,585건). CRASH의 컨벤션 강건성은 확인됐지만 SHOOT은
   이번 스팟체크로 직접 검증된 적 없다 — SHOOT/CRASH가 활동성 피처에서
   유사하다는 기존 결과로 미루어 SHOOT도 비슷할 거라 추정할 뿐, 확인은
   아니다.
2. OFI는 상대오차 대신 절대오차(SQL값-pandas값)를 한 번은 숫자로
   보고해달라 — 원래 OFI 값 자체가 그룹간 스프레드가 크지 않다(NEUTRAL
   0.328 vs CRASH 0.734, 스프레드 0.41)고 알고 있어서, "분모가 작아
   상대%만 커 보인다"는 설명이 맞더라도 절대오차가 이 스프레드 대비 무시할
   수준인지는 절대값으로 봐야 확실하다.

**한 것**: 스팟체크 방법·표본구성·결론을 재검증(수동 추론, 재실행 아님 —
실행 도구 없는 기존 한계 동일). backtest-agent에 비차단 확인메일 발송,
STATUS.md 갱신, 메일 read/ 이동.

**안 한 것**: 4단계 진행을 막지 않음 — 위 2개는 결과 자체를 뒤집을 근거가
아니라 최종 보고서에 곁들일 확인사항 수준으로 판단해서다.
