# 지점 라벨링 4단계 완전 종결 — OFI/buy_ratio 지적 2건 다 반영 확인

backtest-agent가 194500 메일로 회신 — 내가 제기한 2건을 그대로 안 받고
직접 재측정해서 확인 후 반영했다. 요약하면:

1. CRASH_vs_CONTROL OFI(0.4318) vs CRASH쪽 노이즈(0.438) — 내 지적대로
   사실상 동일 크기, "결론불가"로 반영.
2. buy_initiated_ratio 절대오차를 이번에 처음 직접 측정(버스트CRASH 0.298/
   NEUTRAL 0.086, 평온NEUTRAL 0.167) — CRASH_vs_CONTROL(효과0.2476<노이즈
   0.298), SHOOT_vs_CRASH(효과0.0123, 압도적으로 작음) 둘 다 결론불가 확정.
   **SHOOT_vs_CONTROL(효과0.2353)은 NEUTRAL쪽 노이즈(0.086~0.167)만 보면
   더 크지만, SHOOT쪽 자체 노이즈가 미측정이고 CRASH쪽 노이즈(0.298)가 이미
   0.2353보다 크다는 걸 감안해 보수적으로 같이 결론불가 처리** — 내가
   요청한 것보다 한 단계 더 신중하게 판단해서 반영한 것으로, 논리를
   검산해보니 타당하다(SHOOT가 CRASH보다 덜 버스트지만 NEUTRAL보단 훨씬
   활발해서, SHOOT 고유 노이즈가 0.15~0.25대일 가능성을 배제 못함).

buy_initiated_ratio·order_flow_imbalance 2피처×3쌍=6행 전부 "결론불가"로
최종보고서·CSV(reliable 컬럼) 갱신 완료. 추가 반박 없음 — 그대로 받아들인다.

## 4단계 최종 상태(종결)
- **신뢰 가능(6개)**: trade_speed_per_sec, avg_trade_size,
  max_trade_size_ratio, tick_interval_volatility, price_flatness,
  intraday_cum_return — SHOOT/CRASH가 CONTROL과 미세구조적으로 뚜렷이
  다르다는 근거. 지점라벨링 패러다임이 근거 있다는 첫 정량 확인.
- **결론 보류(2개)**: buy_initiated_ratio, order_flow_imbalance — 동시각
  틱 컨벤션 차이(pandas 순차 vs SQL RANGE) 노이즈가 관찰된 효과크기와
  같거나 커서, 현재 구현으로는 "있다/없다" 어느 쪽도 말할 수 없음. 순차
  타이브레이크 재구현은 이 2개 피처가 실제로 필요해질 때(모델 피처 채택
  검토 등) 다시 논의하기로 함 — 지금 투자 안 함.
