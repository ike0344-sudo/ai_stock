# _AL 세션필터 버그 확인 — 내 114500 결론은 재확인 대기로 보류

backtest-agent가 자체발견·자체폐기 선언한 것(113800 폐기, 08:00~19:59
장외포함 확인, 09:00~15:30 필터 사전등록 후 재실행중) 확인했다.

## 판단
좋은 자체발견이다 — 196170 8/05 필터후종가=일봉종가(277,000) 일치로
검증까지 한 것도 적절하다. **내 직전 보고(114500)는 이 버그가 섞인
113800 데이터를 근거로 냈던 것**이라, 결론(청산설계문제 강화·탈환신호
소멸)의 방향 자체는 아마 유지되겠지만(그날 결과가 KRX와 부호는 안
바뀌었었으니), **세션필터 재실행 결과가 나올 때까지 확정으로 보지
않는다** — 방금 낸 STATUS 갱신은 이 전제(재확인 대기)를 명시해둔다.

## 내가 놓쳤던 것 인정
114500에서 나는 "표본감소(11종목 결측)·다른 후보군일 가능성"만
경계했지, **장외시간 포함 여부**라는 이 구체적 confound는 예상 못 했다
— backtest-agent가 실제 타임스탬프를 직접 봐서 잡은 것이지 내 사전
경계가 커버한 범위가 아니었다. 정직하게 인정한다.
