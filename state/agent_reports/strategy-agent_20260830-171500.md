직접 읽고 확인했다(받아쓰지 않음).

## 홀드아웃 오픈 건 — 절차 정상
사용자 직접 지시로 열렸고, 목적(분봉근사 왜곡 "측정", 파라미터선택/전략채택 아님)과
"다시 홀드아웃으로 못 씀" 경고까지 명시돼 있다. 문제 삼을 것 없음, 확인만.

## 핵심 발견: ka10079(틱)가 KRX 전용 — NXT 누락, 방향확정/크기미상
조건1(3분거래대금 40억)이 원래도 최대 병목이었는데 이게 KRX 단독 거래대금이라
실질적으로 더 빡빡했다는 뜻. 이건 인트라데이(전략1) 얘기라 이미 우리가 무게중심을
옮긴 영역 — 새 위험 아님, 기존 판단(일봉 우선)을 강화하는 방향.

## 내가 새로 판 것 — 확인 필요, 스스로 결론 안 냄
`kiwoom_client.py:183-187` `get_daily_chart`(ka10081, **data/stocks/daily/*.csv의
원천, 내 new_high_swing 계열 전부가 이걸 씀**)를 직접 열어보니 `stex_tp` 필드를
아예 안 보낸다 — ka10080(분봉)이 "필드 안 보내면 KRX 단독과 동일 동작"이라고
실측 확인된 것과 같은 패턴이고, ka10079(틱)도 "필드를 아예 안 읽어 KRX만" 이라는
게 오늘 확인된 버그다. **세 TR이 같은 결함을 공유할 가능성이 있는데, ka10081
자체는 이번 조사에서 한 번도 실측 검증된 적이 없다 — 내가 가진 코드만으로는
확정 못 한다(추정일 뿐).**

만약 사실이면 파급이 크다: new_high_swing/new_high_leg_exit/new_high_volume_
divergence_exit/vcp_breakout 전부가 KRX 단독 일봉 위에서 만든 것이 되고, 방향은
아마 오늘 확인된 것과 같은 과소집계(거래량/신고가 판정이 실제보다 보수적)일
가능성이 높다 — 다만 이것도 추정이다.
