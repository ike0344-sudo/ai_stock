# top25+rank1 부분집합 결과 확인 — 채택 안 함, 완전히 종결

backtest-agent 결과(223200) 확인 — 혼동행렬을 역산해서 검증했다(recall/
precision/정확도가 서로 수학적으로 일치하는지: 로지스틱 TP≈18,304/
TN≈15,721로 역산하면 정확도 (18,304+15,721)/74,584≈45.6%, 보고된 45.62%와
일치 — 숫자 자체는 신뢰한다).

**판정 동의**: 게이트 통과(표본충분, (종목,날짜) 30개로 일화적 아님)했지만
정확도가 전체표본보다 **더 나쁘다**(로지스틱 45.62%는 이 부분집합 자체의
다수클래스 기준선 58.94%보다도 낮음 — 찍는 것보다 못함). recall(CRASH)/
precision(SHOOT) 개별 하한 통과를 "부분성공"으로 포장 안 한 것도 맞는
판단 — 주 판정기준(정확도+날짜별 과반) 실패면 그게 결론이다.

**내가 추가한 해석 하나**: 역산해보니 로지스틱의 recall(SHOOT)≈41.6%다 —
이 부분집합의 다수클래스(SHOOT 58.94%)조차 동전보다 못 맞춘다. 왜 전체
표본보다 더 나빠졌는지에 대한 가설: "거래대금25위+등락률1등"으로 이미
한 번 걸러진 표본은 정의상 이미 "그 순간 가장 활발한 종목"들이라, 6개
신뢰피처(전부 활동성 계열)의 **분산 자체가 이 부분집합 안에서 크게
줄어든다**(range restriction) — 전체표본에서는 활동성이 낮은 CONTROL성
사례와 대비돼 변별력이 있던 피처들이, "이미 다 활발한" 집단 안에서는
서로 구분이 잘 안 될 수 있다. 확정 아니고 해석이다.

## 처리
- 사전등록 문서에 결과 요약 추가함(`docs/TOP25_RANK1_DIRECTION_PREREGISTRATION.md`).
- 이 조건(25위+1등)은 방향판정 필터로 **채택 안 함** — 이번 라운드 완전
  종결. 사전등록 §6대로 "통과선도 못 넘었으니 채택여부 논의 단계에도
  못 갔다"는 backtest-agent 정리에 동의, 추가 조치 없음.
