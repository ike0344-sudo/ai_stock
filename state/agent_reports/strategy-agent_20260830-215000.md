# 2단계 방향판정 결과 판단 — "약한/경계선 신호", 수익구조 단계로 아직 안 넘어간다

backtest-agent 결과(214500) 받아서 혼동행렬을 직접 손으로 재검산하고 내가
사전 등록한 기준을 다시 적용해봤다. 좋은 실험이었고 숫자도 내부적으로 다
맞다 — 다만 결론은 "명확히 의미 있다"가 아니라 "경계선상, 아직 확신 없다"다.

## 검산 결과 (전부 일치, 신뢰함)
- 로지스틱 혼동행렬 합: TN+FP=176,683 / FN+TP=174,294 → 검증구간 실제
  CRASH/SHOOT 카운트와 정확히 일치. 트리도 동일하게 일치. 정확도(55.19%/
  56.09%)도 직접 나눠서 재확인, 맞다.
- 표준오차 계산(0.5 대비 ~0.084%p)도 재검산 일치 — 차이가 우연이 아니라는
  주장은 맞다. **다만 "우연 아님"과 "실전에 쓸 만큼 큼"은 다른 얘기다** —
  가설C(OFI다이버전스)에서 통계적으로 진짜인 +37% lift도 결국 비용을 못
  뚫었던 걸 기억해야 한다. 이번에도 같은 함정을 피해야 한다.

## 내 사전 기준을 스스로 고쳐서 재적용함 (결과 보고 기준을 낮춘 게 아니라,
## 기준이 참조하던 숫자 자체가 틀렸다는 걸 발견해서 고침)
내가 사전에 정한 기준은 "53.1%(전체 클래스비율) 대비 +5%p(≥58%)"였다. 그런데
backtest-agent가 검증구간 자체의 실제 다수클래스 비율이 50.34%(전체
53.15%와 다름 — 학습/검증 구간 클래스분포가 이동함)라는 걸 찾아냈다. 내
기준의 **원칙**(적절한 기준선 대비 +5%p)은 안 바꾸지만, 그 원칙이 가리키는
**숫자**는 53.1%가 아니라 50.34%였어야 한다 — 이건 결과를 보고 기준을
느슨하게 바꾼 게 아니라, 기준을 세울 때 쓴 입력값(전체 기간 클래스비율)이
검증구간엔 안 맞았다는 걸 뒤늦게 알게 된 것이다(클래스분포 자체는 모델
성능과 무관한, 데이터분할의 성질이라 이 교정은 리크가 아니라고 판단).

**교정된 기준 = 50.34%+5%p = 55.34%.** 로지스틱 55.19%는 **이 기준에 살짝
못 미친다**(-0.15%p). 결정트리 56.09%는 **살짝 넘는다**(+0.75%p). 둘 다
경계선 바로 위아래다 — "확실히 의미 있다"고 부르기엔 너무 아슬아슬하다.

## 가장 쓸모있는 발견 — 아쉬운 정확도보다 이게 더 중요하다고 본다
혼동행렬을 다시 풀어보니 두 모델 다 **SHOOT 쪽 recall이 CRASH보다 훨씬
높다**: 로지스틱 SHOOT recall 75.5% vs CRASH recall 35.2%(예측의 70%가
SHOOT), 트리는 SHOOT recall 68.7% vs CRASH recall 43.6%(예측의 62.5%가
SHOOT). 즉 이 모델은 "떡락 탐지기"로는 약하지만 **"진짜 슈팅인지 확인하는
용도"로는 상대적으로 낫다** — 사용자가 신고가추세매매(롱 위주)를 지향한다는
걸 감안하면, 아쉬운 전체 정확도보다 이 비대칭이 실제로 더 쓸모 있는
정보일 수 있다.

## 피처 중요도 — 다중공선성 캐비엇 하나 추가
로지스틱과 트리의 순위가 크게 다르다(특히 trade_speed_per_sec: 로지스틱
2위 vs 트리 꼴찌). backtest-agent는 "다른 상관 피처가 이미 설명해버렸을
가능성"으로 해석했는데(확정 아니라고 명시함), 나는 여기에 **다중공선성**
캐비엇을 더한다 — speed/avg_trade_size/max_trade_size_ratio/flatness는
전부 "이 순간이 얼마나 활발한가"류라 서로 상관이 높을 가능성이 크고, 이런
경우 로지스틱 계수는 "누구에게 공을 돌릴지"가 불안정해진다(교과서적
현상). **두 모델이 공통으로 상위권에 놓은 유일한 피처는
intraday_cum_return**(로지스틱 4위/트리 압도적 1위)이라 이게 가장 믿을
만한 단일 신호라고 본다 — trade_speed_per_sec가 "쓸모없다"는 결론은
상관행렬 확인 전엔 성급하다.

## 요청 (급하지 않음, 재학습 아니고 이미 있는 결과 재활용만)
1. **ROC-AUC** — 이미 계산된 예측확률(predict_proba)로 바로 나온다, 재학습
   없음. 정확도 하나보다 판별력을 더 잘 보여준다.
2. 예측확률이 **더 확신 있는 지점만**(예: P>0.65) 골랐을 때 정확도/정밀도가
   얼마나 오르는지 — 이미 학습된 모델의 확률출력을 다른 문턱값으로 다시
   읽는 것뿐이라 "재학습·피처추가 금지" 규칙 위반 아니다. 실전에서는 모든
   burst를 다 판정할 필요 없이 확신 높은 것만 골라도 되기 때문에, 이게
   "쓸 만한가"에 더 가까운 질문이다.
3. (선택) 6개 피처 상관행렬 — 다중공선성 확인용, 급하지 않음.

## 판단 — 아직 수익구조 단계로 안 넘어간다
경계선 결과라서 지금 바로 "의미 있음 확정, 3단계(수익구조) 가자"로 못
간다. 위 1·2번(재학습 없는 재활용 확인) 받고 나서 다시 판단하겠다 — 특히
확신 높은 지점만 골랐을 때 정확도가 확실히 올라간다면(예: 65%+) 그건
"전부 판정하려 하지 말고 확신 있는 것만 쓰자"는 실전적인 다음 설계로
이어질 수 있다.

## 안 한 것
재학습/피처추가/하이퍼파라미터 재탐색 요청 안 함(사전 정지규칙 그대로 지킴).
상관행렬은 급하지 않다고 표시(선택사항).
