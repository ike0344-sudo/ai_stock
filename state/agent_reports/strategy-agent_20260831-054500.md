# 상한측정+탈환실험 판단 — 탈환 정의완화 보류 권고, 오늘 틱기반 추가실험 중단 제안

backtest-agent 두 결과(051500 CEILING, 052500 TAKEOVER) 확인, 검산 후 판단.

## 검산
CEILING: 청산사유 15+17+19+1=52(n일치), 비율(28.8/32.7/36.5/1.9%) 전부
재계산 일치. 일별수익률 합산(직접 18개 항목 더함)≈+9.57%p, 보고된
+9.56%와 일치(반올림 차이). 8/18 하루(+3.62%p)가 전체의 37.9%(3.62/9.56)
차지 — 계산 확인. TAKEOVER: 228+3+2=233(일치), 3/5=60.0%(일치),
burst_detected 0.43%가 CONTROL(0.0045%)의 96배·SHOOT(3.37%)·CRASH(4.84%)
보다는 훨씬 낮다는 것도 재계산해 확인 — 세 그룹 다 §1의 "NEUTRAL에 가까운
성격" 관찰과 방향이 맞다(교차검증 통과).

## CEILING에서 가장 중요하다고 본 발견 (backtest-agent가 이미 짚었지만 강조)
**방향을 100% 맞춰도(SHOOT 라벨 자체로 진입) 손절(32.7%)이 익절(28.8%)
보다 많다.** SHOOT는 "60초 안 어딘가에서 +3%"만 보장하지 진입 직후
일직선 상승을 보장 안 하므로, 방향예측을 아무리 개선해도(호가 포함)
**진입 타이밍/되돌림 문제**로 인한 손절은 못 없앤다 — 이건 방향판정과는
완전히 다른 축의 문제(청산설계: 손절폭·진입타이밍)다. 오늘 하루 종일
"호가로 방향을 개선하면 되는가"를 물었는데, 이 발견은 "방향을 다 맞혀도
청산설계 자체의 한계가 남는다"는 걸 보여준다 — 호가 투자의 기대효과를
평가할 때 반드시 감안해야 할 별도 변수로 기록해둔다(지금 당장 청산설계
개선 작업을 새로 벌이자는 건 아니다, 다음에 고려할 후보로만 남긴다).

## 판단 1 — CEILING(25위+1등, 정적) 결론에 동의
상한 자체가 작고(+9.56%/18일, 8/18 하루가 38%) 자본 대부분이 논다(5슬롯 중
실사용 52건뿐) — 이 조건에 호가 투자할 근거는 약하다는 결론에 동의한다.

## 판단 2 — 탈환(rank2→rank1) 정의완화, 지금은 보류 권고
사전등록(001500) 위반 없이 결과를 정직하게 보고한 것 자체는 잘한 일이다.
**완화해서 바로 재시도하는 것은 권하지 않는다.** 이유:
1. burst_detected 비율(0.43%)이 SHOOT(3.37%)·CRASH(4.84%)보다 훨씬 낮다
   — 표본이 작아서가 아니라 **탈환 이벤트 자체가 활동성 측면에서도
   NEUTRAL에 가깝다는 두 번째 독립 신호**다(정의를 완화한다고 이 성질이
   바뀔 근거가 약함).
2. 오늘 하루에 이미 6개 독립 실험(2단계 전체표본/25위+1등 부분집합/
   threshold_rule K6→K5/CEILING/TAKEOVER 2갈래)을 돌렸다 — 각각은
   개별적으로 사전등록·정지규칙을 잘 지켰지만, **하루에 이렇게 많은
   조건을 계속 새로 만들어 시험하면, 그 자체가 다중비교 위험을 키운다**
   (개별 시험은 깨끗해도 전체적으로 "뭔가 나올 때까지 계속 새 조건을
   만드는" 모양이 될 수 있다). 지금은 새 조건을 하나 더 여는 것보다
   멈추는 게 맞다고 본다.

## 판단 3 — 오늘 전체 그림: 틱 기반 추가 실험은 여기서 멈춘다
오늘 나온 결과를 모으면 방향이 일관된다: 전체표본 방향판정(약함)→
25위+1등 부분집합(더 나쁨)→threshold_rule(K=5는 살아있으나 방향모름)→
CEILING(방향 다 맞혀도 청산설계 한계로 상한 작음)→탈환(활동성 자체가
NEUTRAL에 가까움). **틱만으로 방향을 잡으려는 시도는 오늘 결과로 충분히
검증됐다고 본다 — 추가로 새 조건(3등 이하 등극, 유지시간 단축 등)을
계속 만들어 시험하는 것은 이번 라운드에서 중단을 권한다.** 호가
사전등록(45~65거래일) 일정대로 가고, 그 전까지는
`docs/ORDERBOOK_DIRECTION_PREREGISTRATION.md` §6의 "8월과 무관한 준비
작업"(새 피처 함수 합성데이터 자체점검 등)으로 넘어가는 게 낫다고 본다.

## 안 한 것
탈환 정의완화 사전등록 새로 안 씀(위 판단에 따라 보류). 청산설계 개선
설계 착수 안 함(기록만, 범위 밖). CEILING/TAKEOVER 결과 자체에 대한
추가 재실행 요청 안 함(사전등록·정지규칙 다 지켜졌다고 확인했으므로).
