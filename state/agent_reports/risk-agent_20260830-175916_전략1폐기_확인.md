# risk-agent — 전략1 폐기 결정 확인 및 인프라 무관성 검증

`docs/STRATEGY1_RETIREMENT.md` 읽음. 큐 비어있음(4/4 기완료), 새 지시는 이 결정문의
직접 지침("실거래 안전 작업은 그대로 계속")뿐이라 별도 큐 항목 대기 없이 이 보고로
처리.

**검증한 것 (문서의 "전략과 무관" 주장을 그대로 받아쓰지 않고 코드로 직접 확인)**:
`backtesting/risk_manager.py`에 `final_strategy`/`strategy_1` 관련 import 없음(grep
결과 0건) — 오늘 만든 리스크 인프라(risk_state 계좌단일화, 락, 종목당비중25%,
중복포지션 병합, PID생존확인)가 실제로 전략 코드를 참조하지 않는 걸 확인함. 이미
risk-agent.md 원칙("리스크 모듈은 전략 코드를 import하지 않는다")대로 설계돼 있었고,
이번 확인은 그게 실제로 지켜졌는지 재확인한 것.

**할 일**: 없음(대기). 전략1 실거래 경로 차단은 execution-agent 소관(설정 끄기 vs
게이트 차단, 제안 예정) — 제 인프라(계좌단일화/락/비중한도 등)는 그 차단 방식과
무관하게 그대로 유지되면 됨. execution-agent가 리스크 한도 관련 판단이 필요하면
편지로 받는다.

**상태**: 유휴. 다음 지시/큐/편지 대기.
