# 일봉 3축 측정 — 방향 재설정 라운드 (2026-08-31)

## 0. 결론 (한 줄)
**H1·H2·H3 전부 기각.** IS(280개 리밸런스 시점, 2019-04-30~2024-12-31)
첫 기각조건에서 셋 다 걸렸다 — OOS는 사전등록 규칙대로 안 봤다("IS에서
죽으면 OOS 안 봐도 됨"). standing.md 규율대로 새 가설을 스스로 만들지
않고 이 리포트로 lead에게 방향 재설정을 요청한다. **핵심 발견**: H1의
총수익은 실제로 양수(+0.227%)였는데 **그 전부가 오버나이트 갭에서
나왔다** — 장중전용(H3)으로 떼어보니 총수익이 오히려 마이너스(-0.156%,
t=-3.94로 유의하게 음수)였다. 이건 틱 기반 1차 라운드(`backtest-agent_
20260831-184553_holding_horizon.md`)에서 이미 본 "갭이 수익의 대부분"
패턴이 **완전히 다른 데이터(일봉 vs 틱), 완전히 다른 신호 정의(ret_5d
퀸타일 vs price_speed 문턱)로도 그대로 재현된 것**이다 — 우연이 아니라
이 시장의 구조적 특징일 가능성이 커졌다.

## 1. 검증 없이 안 받은 것
사전등록의 "2,413종목"(strategy-agent가 lead의 구버전 "1,048"을 정정한 값)을
그대로 안 믿고 `data/stocks/daily/` 직접 Glob으로 재확인 — **정확히
2,413개 파일 일치.** 계산량 문제도 사전에 200파일 표본으로 로딩시간을
측정해(3.5초 추정) 그리드를 완화할 필요가 없다고 판단, 실제로도 전체
로드 3.8초/포트폴리오 계산 14.5초로 문제없었다.

## 2. 파이프라인
- 캘린더: 전 종목 date 합집합(개별 종목 결측은 캘린더를 안 왜곡함).
- 리밸런스 그리드: 5거래일 간격, `t-5`(피처)와 `t+1..t+5`(체결)가 전부
  캘린더 안에 들어오는 지점만.
- 신호는 t일 확정 종가까지만 사용(`ret_5d[t]`, `clv[t]`), **진입은 t+1일
  시가**, 청산은 H1/H2 종가-종가(갭 포함) / H3 장중전용(매일 시가→종가
  5일 복리, 갭 제외).
- 표본 단위: 리밸런스 시점 1개 = 그 시점 동일가중 포트폴리오 수익률 1개
  (종목x일 아님).
- 비용 0.0052(사전등록 상속값 그대로, 재검증 안 함 - 소형주 비중이 큰
  이 유니버스에선 과소평가 위험이 있다는 한계를 사전등록대로 계승).

## 3. 표본 규모 (직접 확인)
| | IS(2019-04-23~2024-12-31) | OOS(2025-01-01~2026-08-31) |
|---|---|---|
| H1/H2/H3 공통 그리드 | 280건 | 79건 |

**최소표본(IS 200개) 충족.** 크로스섹션 크기(퀸타일 모집단)는 2019년
149종목→2026년 최대 475종목으로 **약 3.2배 성장**(사전등록이 미리 경고한
"패널 불균형" 그대로 확인됨). H2의 `high==low`(가격제한 등) 제외 비율은
0.25%~2.41%로 10% 문턱을 안 넘어 별도 경고 불필요.

## 4. H1 — 눌림 후 반등 (기각)
| | 값 |
|---|---|
| IS Q1(눌림군) 총수익 평균 | +0.227% |
| IS Q1 순수익(비용 0.52% 차감) 평균 | **-0.293%** |
| t(단측) | -1.07 |
| 기각조건1(순수익>0, t≥1.65) | **기각** |

총수익 자체는 플러스지만 비용을 못 넘는다(t도 애초에 1.65는커녕 양수도
아님). 쌍대차(Q1-Q5)·OOS는 안 봤다(사전등록 규칙).

## 5. H2 — CLV(종가 위치) 낮으면 반등 (기각)
| | 값 |
|---|---|
| IS Q1(CLV최저) 순수익 평균 | **-0.341%** |
| t(단측) | -1.44 |
| 기각조건1 | **기각** |

이쪽은 총수익 자체가 마이너스에 더 가깝다(총수익 -0.341%+0.52%=+0.179%,
H1보다도 약함). "순매도 우세"의 일봉 대응물(CLV)은 H1(ret_5d 눌림)보다
약한 신호였다.

## 6. H3 — 갭 vs 장중전용 (기각, 핵심 발견)
| | 값 |
|---|---|
| IS 장중전용(갭 제외) 순수익 평균 | **-0.676%** |
| t(단측) | **-3.94**(유의하게 음수) |
| (비교) IS 갭포함(H1 Q1) 총수익 평균 | +0.227% |
| 기각조건1 | **기각("갭 의존적"으로 결론)** |

장중전용 총수익 = -0.676%+0.52% = **-0.156%(음수)**. 즉 **H1의 플러스
총수익(+0.227%)은 100% 이상이 오버나이트 갭에서 나왔고, 장중 움직임만
따로 떼면 오히려 마이너스다** — 갭을 빼면 신호 자체가 반대 방향이 된다.
t=-3.94로 이 음수 자체는 통계적으로 뚜렷하다(우연이 아니라 장중에는
진짜로 반대 경향이 있다는 뜻).

**틱 라운드와의 교차검증**: `holding_horizon.py`(1차, 틱 기반, 다른
신호(price_speed 세창 하위10%))에서도 "IS 순수익 개선의 74~76%가 갭"
이라는 걸 발견했었다(`backtest-agent_20260831-184553`). 이번엔 아예
**일봉·다른 신호(ret_5d 퀸타일)로 갭 의존성이 100%를 넘는(장중은 반대
부호) 더 극단적인 형태로 재확인됐다** — 서로 다른 두 실험이 같은 방향의
결론에 도달했다는 게 이 발견의 신뢰도를 높인다.

## 7. 종합 — standing.md 규율 발동
H1·H2·H3 **전부 첫 기각조건에서 걸렸다**(판단보류 없이 깔끔하게 3개 다
기각). standing.md 규율대로 새 가설을 스스로 만들지 않고 여기서 멈춘다.
**[요청] 방향 재설정 필요 — lead 판단 요청.** 참고로 남길 만한 단서:
- 갭이 핵심 동력이라는 패턴이 두 라운드(틱/일봉) 연속으로 나왔다 —
  "오버나이트 갭 자체를 잡는 전략"(장 마감 매수-다음날 시가 매도, 혹은
  그 반대)을 별도 축으로 검토해볼 여지가 있다(이번 조사 범위 밖, 제안만).
- 장중 신호는 오히려 반대 부호(H3)라 "장중 눌림 후 반등"이 아니라 "장중
  모멘텀 지속" 쪽에 더 가까울 수 있다는 힌트도 있다(깊게 안 팜).
