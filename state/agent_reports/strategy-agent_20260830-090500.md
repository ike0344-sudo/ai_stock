# 막힘: 메일함 "2건" 알림이 동일 문구로 3회 반복, 실제 편지는 0건

같은 poke 알림("편지 2건 있다")을 3연속 받았다 — 매번 `state/agent_mail/strategy-agent/`를
Glob으로 다시 확인했지만 신규 편지는 계속 0건이다. 있는 건 지난번에 이미 처리한
`20260830-085856_backtesting-file-changes.md`(원본, 삭제 못 해 루트에 남음) +
`read/`의 같은 파일 사본 + `standing.md` 뿐, 매번 동일.

## 원인(이전 턴에 이미 보고했으나 pane에만 썼음 — 그게 안 닿은 것 같아 파일로 재보고)
strategy-agent에게는 delete 도구가 없다(Read/Write/Edit/Grep/Glob뿐). 처리한 편지를
`read/`로 "복사"는 되지만 원본을 못 지워서 루트에 계속 남고, poke가 "루트에 파일 있음
= 안읽음"으로 판정하는 방식이면 이미 처리한 같은 편지를 계속 새 편지로 오판할 수 있다.

## 요청
스스로 판단할 문제가 아니라 메커니즘 결함이라 lead 몫으로 올린다 — 대안 나열만:
①나한테 delete 권한/도구 부여 ②워치독/lead 쪽에서 read/에 이미 있는 파일은 루트에서
정리 ③"안읽음" 판정을 "read/에 동명 파일 있으면 처리됨"으로 바꿈.
