# threshold_rule.py K=5 완화 재측정 결과 (2026-08-30)

확인 후 실행. 오염제거 CONTROL 풀 재구성(66,781,118행 일치) → 문턱값
재도출(이전 실행과 소수점까지 일치) → K=6/K=5 둘 다 측정.

## 결과

| K | CONTROL | SHOOT | CRASH |
|---|---|---|---|
| 6(전부, 이전 결과 재확인) | 0/10,000,000 (0%) | 0/591,756 (0%) | 0/521,564 (0%) |
| **5** | 450/10,000,000 (**0.0045%**) | 19,939/591,756 (**3.37%**) | 25,239/521,564 (**4.84%**) |

**정지규칙 판정(사전등록, strategy-agent 220100+223600)**: "K=5도 세 그룹이
비슷하면 멈추고 AND형 자체가 안 된다고 결론" — 이번엔 **비슷하지 않다**.
SHOOT/CRASH 발동률이 CONTROL 대비 각각 **749배·1076배** 높다. AND형
결합(K=5)이 CONTROL과 SHOOT/CRASH를 뚜렷이 가른다 — K=6까지는 과도했지만
K=5는 살아있는 신호로 보인다.

CRASH(4.84%)가 SHOOT(3.37%)보다 1.44배 높게 나오지만, 이 규칙 자체가
방향을 모른다는 원래 설계(§docstring)는 그대로다 — burst_detected는
여전히 불리언이지 방향 신호가 아니다.

## 소요시간 (참고, 다음 지시 관련)

(18분) — 오늘 같은 풀을 3번째 재구성한 것(4단계 버그수정/1차
