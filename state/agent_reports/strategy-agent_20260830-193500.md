# 4단계 최종결과 독립검증 — OFI/buy_ratio "신뢰불가" 범위를 CONTROL비교까지 확장 제안

**결론**: backtest-agent 4단계 결과(backtest-agent_20260830-193200_stage4-final.md)
그대로 안 받고 검산했다. 6개 피처는 수긍, 2개 피처는 backtest-agent보다 더
보수적으로 봐야 한다고 판단 — lead 판단 요청.

**검산해서 수긍한 부분**: (1) reservoir 목표크기 556,660 =
(591,756+521,564)/2 직접 계산해 일치. (2) 조인버그 수정 방향(CONTROL을
실제보다 활발하게 보이게 하는 방향)과 수정 후 결과변화 방향(차이가 더
벌어짐)이 논리적으로 일치. (3) CONTROL(오염제거) 중앙값을 3단계 원시
NEUTRAL 전체와 비교하니 방향이 이치에 맞게 소폭만 이동(speed 2.8→2.62,
avg_size 30.9→28.83 등, 제외 대상이 전체의 일부뿐이라 타당) — 파이프라인
정상 동작으로 판단.

**동의 안 한 부분**: backtest-agent는 OFI/buy_ratio "신뢰불가"를
SHOOT-vs-CRASH 비교에만 적용하고 SHOOT/CRASH_vs_CONTROL은 "노이즈 대역
근처지만 유효"로 남겼다. 과도하게 관대하다고 본다 — CRASH_vs_CONTROL의
OFI 효과크기(+0.4318)는 자체 측정한 CRASH쪽 노이즈(0.438)와 사실상 같은
크기다("근처"가 아니라 "구분 불가" 수준). 게다가 buy_initiated_ratio는
이번 스팟체크에서 절대오차가 한 번도 직접 측정 안 됐다(OFI만 측정,
buy_ratio는 "같은 부류 피처"로 유추 적용된 것으로 보임 — 확인 요청).
SHOOT쪽 노이즈는 backtest-agent도 이미 인정했듯 아예 측정된 적 없다.

**요청한 조치**: OFI·buy_initiated_ratio 관련 3개 비교(SHOOT_vs_CONTROL,
CRASH_vs_CONTROL, SHOOT_vs_CRASH) 전부를 "이 데이터로는 결론 불가"로
통일 표기해달라고 회신함 — SHOOT-vs-CRASH만 그렇게 쓰고 나머지 둘을
"유효"로 남기면 독자가 잘못된 확신을 가진다.

**전체 그림(내 판단, 핵심)**: 8개 중 6개(체결속도·평균체결크기·최대체결
비율·틱간격변동성·price_flatness·intraday_cum_return)는 SHOOT/CRASH가
평범한 시장상태와 미세구조적으로 다르다는 증거로 신뢰할 만하다 —
지점라벨링 패러다임이 근거 있다는 첫 정량적 확인(규칙우선 전략1의 -12.8%
천장과 달리, 실제로 구분되는 상태가 존재함을 보여줌). 나머지 2개(OFI·
buy_ratio)는 현재 SQL 구현 컨벤션으로는 3개 비교 전부 판단 불가 상태로
남겨두고, 이 두 피처가 실제로 필요해지는 시점(모델 피처 채택 검토 등)에
순차 타이브레이크 재구현 여부를 논의하는 게 낫다고 본다 — 지금 재구현에
투자할 필요는 없음(탐색 단계, 6개만으로 핵심 가설은 이미 검증됨).

**다음 단계**: 모델 학습은 아직 이르다고 본다 — 표기 정정 회신 받은 뒤,
6개 검증 피처로 단순 임계값 규칙 vs 분류모델 중 방향을 다음에 이어서
설계하겠다(이번 턴엔 착수 안 함).

**안 한 것**: 원본 수치 재계산 안 함(실행 도구 없음, 기존 한계 동일).
모델링 설계 착수 안 함(범위 밖, 다음으로 넘김).
