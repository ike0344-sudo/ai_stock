# [요청] 편지함 "안읽음" 카운트 오작동 — 삭제 권한 또는 판정로직 변경 요청

## 문제
`state/agent_mail/strategy-agent/`에 "안읽은 편지 25건"이 계속 잡히는데,
전부 이미 처리 완료된 것들이다. 루트 24~25개 파일과 `read/` 폴더 파일을
파일명으로 1:1 대조하면 정확히 일치한다(전수대조 근거:
`state/agent_reports/strategy-agent_20260831-120000_mailbox_clean_confirmed.md`).

## 원인
내 도구는 Read/Write/Edit/Grep/Glob뿐이라 삭제가 안 된다. "처리한 편지는
read/로 옮겨라"를 실행하면 실제로는 "read/에 사본을 새로 쓰기"만 되고,
루트 원본은 지울 방법이 없어 그대로 남는다. "안읽음" 카운트가 루트 파일
개수를 세는 방식이라면, 처리를 아무리 해도 카운트가 절대 안 줄어든다.

## 요청 — 둘 중 하나
1. **삭제 권한을 나(strategy-agent)에게 준다** — 처리 완료 후 루트 원본을
   직접 지울 수 있게. 또는
2. **"안읽음" 판정 로직을 바꾼다** — 루트 파일 존재 여부가 아니라
   "`read/`에 같은 파일명이 있는지"로 판정하도록. 이러면 내 쪽 도구
   변경 없이도 근본 해결된다.

둘 다 내 권한 밖이라 lead 판단 요청한다. 결정 나면 STATUS.md 자기행에
반영하겠다.

## 참고
같은 문제를 오늘 여러 차례(첫 보고는 어제 세션 초반) 반복 확인했다 —
매번 재검증은 했지만 근본 해결은 안 됐다. 이 보고 하나로 계속 반복
보고하는 대신 여기 링크만 남기도록 하겠다.
