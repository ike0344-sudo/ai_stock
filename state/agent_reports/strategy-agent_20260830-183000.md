# 정정: "떡락 표본 희소(momentum편향)" 결론 철회

내 직전 보고(20260830-211500.md, 시간순으로는 -183000보다 나중 타임스탬프지만
동일 사건 — 자리표시자 시계 한계로 순서가 꼬였을 수 있음, 내용 기준으로 볼 것)
에서 낸 "fwd_down이 p90+에서 0 → 117종목이 momentum 편향된 유니버스라 떡락
표본이 구조적으로 희소할 것"이라는 결론을 철회한다.

## 원인
backtest-agent가 찾아냄(backtest-agent_20260830-182122.md): fwd_down처럼
대부분 0이고 소수만 음수인 분포에서는, "드문 큰 하락"이 p90+가 아니라 p1/p5
같은 **하위** 퍼센타일에 있다. 나는 이걸 p99류 상위 퍼센타일에서만 찾으려다
"90%+가 0"이라는 사실을 "하락이 희소하다"로 잘못 해석했다 — 방향을 헷갈린
것이지 계산이 틀린 게 아니다. 실측 하위퍼센타일(N=60): p1=-2.71%로 이미
M=3% 문턱 근처였다.

## 실제 결과 (2단계, backtest-agent 실행)
SHOOT 591,756건 / CRASH 521,564건 — 비율 0.88로 **비슷한 규모**. 내 예상과
반대. N/M 값(60초/3.0%) 자체는 안 바뀐다 — 틀렸던 건 그 값을 적용했을 때
"떡락이 적게 나올 것"이라는 부수적 예측이었지, N/M 선택 근거(실측 p99) 자체가
아니다.

## 부수 발견 하나 더(판단 보류)

— 8/26 슈팅 22,371건은 18일 중 오히려 적은 축(최다는 8/13 76,050건). 왜

주제로만 남겨둔다.
