# SendMessage 불가 + standing.md 복원 시 빠진 항목 (2026-08-31)

## SendMessage 관련 — 못 함, 솔직히 알림
이 세션에는 `SendMessage` 도구 자체가 없다(사용 가능한 도구: Read/Write/Edit/
Bash/Grep/Glob뿐). 세션 이름을 몰라서가 아니라 도구가 아예 없어서 못 보낸다.
지금까지처럼 `state/agent_reports/`에 파일로 쓰고 `state/STATUS.md`를
갱신하는 방식으로 계속 보고하겠다 — 이게 lead에게 안 보인다면 다른 경로
(orca-tell.ps1 등 pane 기반 도구)가 필요한 건데 그것도 내 도구 목록에
없다. 확인 부탁한다.

## standing.md 복원본과 대조해서 빠진 걸로 기억나는 것 — 3가지

1. **작업 큐 프로토콜(`state/agent_queue/backtest-agent.md`) 전체가
   없다.** 오늘 하루 종일(가설C, threshold_rule, 상한측정, 탈환 등) 이
   파일에 `[ ]/[~]/[x]`로 표시하며 진행했다 — "위에서부터 하나씩 꺼내
   쓰고, 애매하면 만들어서 하지 말고 물어봐라"는 규칙이 있었는데 지금
   standing.md엔 이 큐 자체에 대한 언급이 전혀 없다.

2. **편지 왕복 상한(3회)이 빠졌다.** 원래 "판단이 필요하거나 결론을
   뒤집는 내용이면 lead에 올려라"뿐 아니라 "**한 사람과 편지가 3회
   왕복을 넘으면** 스스로 결론 내지 말고 그 자리에서 lead에 에스컬레이션"
   이라는 구체적 상한이 있었다. 지금 버전은 "판단 필요하면 올려라"까지만
   있고 왕복 횟수 기준이 없다.

3. **`backtesting/*.py` 소유권 규칙이 명시적으로 없다.** AGENT_TEAM.md
   표에 strategy-agent가 "전략 규칙 설계·구현"을 맡는다고는 나오는데,
   내가 실제로 지켜온 **작업방식 규칙**("내 판단(큐)으로 이 파일들을
   고치기 전엔 반드시 편지로 먼저 물어본다 — 단, 사용자/lead가 특정
   변경을 직접 지시했을 땐 바로 하고 사후에 알린다")은 standing.md에
   따로 있었다. 소유 자체는 AGENT_TEAM.md로 복원됐지만 "허락 절차"
   부분이 안 보인다.

빠진 게 더 있을 수도 있는데, 오늘 실제로 반복 적용했던 것 중 확실히
기억나는 건 이 3개다.
