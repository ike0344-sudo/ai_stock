# 지점 라벨링 2단계 — 라벨 추출 결과 + 1단계 해석 정정 (2026-08-30)

## ⚠️ 먼저: 내 1단계 보고서의 해석이 틀렸다 — 정정한다
1단계 보고서(backtest-agent_20260830-181148.md)에서 "fwd_down이 p90 이상에서
거의 항상 0 → momentum 편향으로 떡락이 구조적으로 희소할 것"이라고 썼는데,
**퍼센타일 방향을 잘못 읽었다.** fwd_down은 대부분 0(안 떨어짐)이고 소수만
음수인 분포라, "드문 큰 하락"은 p90+가 아니라 **p1/p5 같은 하위 퍼센타일**에
있다. N=60초 기준 방금 다시 뽑은 하위 퍼센타일: p0.1=-5.76%, **p1=-2.71%**,
p5=-1.34%, p10=-0.88%. p1이 이미 -2.71%로 M=3% 문턱에 근접해 있다 —
"떡락이 희소하다"는 내 원래 해석과 반대로, **실제 임계값 근처에 상당한 표본이
있다는 뜻**이었다. 이 오독을 바탕으로 strategy-agent가 "떡락 표본이 적을
것"이라는 전제를 문서(point_labeling.py:28-32)에 남겼는데, 아래 실측이 그
전제와 다르게 나왔다 — 원인이 내 오독이었다는 것까지 포함해 알린다.

|---|---|---|
| SHOOT(+3%↑) | 591,756 | 0.834% |
| CRASH(-3%↓) | 521,564 | 0.736% |
| NEUTRAL | 69,798,934 | 98.430% |

**SHOOT과 CRASH가 비슷한 규모다(비율 0.88)** — "떡락이 구조적으로 희소하다"는
예상과 다르다. ambiguous(둘 다 걸림, NEUTRAL 처리) 22,259건(전체의 0.031%,
미미함) — CRASH 문턱을 넘긴 원시 건수(543,823)에서 이 ambiguous를 빼면 정확히
521,564로 맞아떨어짐(교차검증 완료).
