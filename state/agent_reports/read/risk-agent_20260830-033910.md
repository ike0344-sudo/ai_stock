1. **사이징**: `total_capital/5` 고정(`trading_loop.py:550`) — 슬롯 1~2개만 차면 자본 유휴화되지만 건당 배팅은 20% 이하로 그대로 묶여 안전쪽 위험 증가는 아님. 의도된 동작인지 전략팀 판단 필요, 값 안 바꿈.
2. **연속손절/일일한도**: `max_consecutive_losses`는 이미 `null`(`risk_limits.yaml:20`)이라 신호감소로 인한 회귀 아님. 일일손실한도는 절대금액 기준이라 거래횟수 무관하게 여전히 유효.
3. **종목당비중**: `null`(`risk_limits.yaml:15`)이라 스킵 중. 좁아진 조건이 같은 종목을 반복 재선정하면 동일종목 중복포지션 리스크가 커짐(별도 버그 — 다음 보고 참고). 권장값 20~25% 제안, 미적용, 승인 필요.
4. **락 검증**: 동시쓰기 테스트 없었음 → `test_risk_manager.py`에 신규 추가·통과. 락 무력화 후 재현 시 JSON 파일 자체 손상(JSONDecodeError) 확인 — 락 있으면 정상.

**미해결**: (3)에서 언급한 동일종목 중복포지션 버그는 별도 보고 참고(발견→디스패치→수정완료).
