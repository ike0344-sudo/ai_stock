# risk-agent 완료 보고 — risk_state 계좌 단일화

**요청**: 전략1+신규전략 동시운용 대비 risk_state를 계좌 단일 파일로 강제, 일일손실 킬스위치 계좌 전체화, `--max-concurrent-positions` 우회 차단.

**한 것**
- `risk_manager.py`에 `risk_state_lock()` 추가(O_CREAT|O_EXCL 파일락, 죽은 락 120초 후 회수) — `trading_loop.py`/`oversold_trading_loop.py`가 매 사이클 이 락 안에서 load→반영→save.
- `cli.py`: `ACCOUNT_RISK_STATE_PATH="state/risk_state.json"` 강제, `--risk-state-path` 플래그 삭제. `--max-concurrent-positions`가 yaml 한도(5) 초과 시 자동 클램프.
- `dashboard_server.py`: `_strategy_path`가 risk_state 키는 전략 무관 계좌공유 경로 반환하도록 수정.

**숫자**: 전체 테스트 `786 passed / 4 failed`(실패 4건은 무관 파일 `test_trading_value_ranking.py`, 세션 시작 전부터 존재 — 측정은 pytest 1회 실행, 실거래 동시성은 미검증).

**diff 재검토에서 발견·수정한 버그**: `oversold_trading_loop.py` heartbeat 2곳이 계좌공유 경로 기준으로 잘못 남아있어 전략2 heartbeat가 전략1과 충돌할 뻔함 — 수정 완료.

**미해결**: 수동 킬스위치(대시보드 버튼)는 여전히 전략별 분리(자동 일일손실 킬스위치만 계좌 통합됨). 락 실거래 동시경합 부하테스트 안 함(단위테스트로만 재현·검증).
