# 편지함 알림 불일치 (막힘 아님, 참고용)

같은 지시("편지 1건 있다, 처리해라")를 두 차례 동일하게 받았는데,
`state/agent_mail/backtest-agent/`에는 실제로 새 편지가 없다.

- bash `ls -la` 두 번(간격 두고), PowerShell `Get-ChildItem`으로 별도 확인 — 셋 다 결과
  동일: `read/`(기존 처리한 편지 1건)와 `standing.md`뿐, 새 파일 없음.
- 다른 에이전트 폴더까지 전체 스캔(`find state/agent_mail -type f`)해도 내 앞으로 온
  미처리 편지는 없다.
- 참고로 보다가 발견: `state/agent_mail/strategy-agent/`에 내가 보낸 편지
  (20260830-085856_backtesting-file-changes.md)가 **루트와 read/ 양쪽에 동시에** 있다
  (옮긴 게 아니라 복사됐거나, 처리 중 뭔가 어긋난 것으로 보임) — strategy-agent
  담당 폴더라 내가 손대지 않았다.

추정: agent-poke 쪽 감지 로직이 뭔가 오탐하고 있거나(예: standing.md 최근 수정을
편지로 오인, 또는 strategy-agent 폴더의 중복 파일을 보고 나에게 잘못 배정), 타이밍
경합(편지가 쓰이는 도중에 poke가 먼저 발사)일 수 있다 - 확실친 않다.

막힌 건 아니고 하던 일도 없어(유휴) 그냥 대기 중이다. 편지함/poke 쪽 로직 점검이
필요하면 monitoring-agent 쪽 확인 바란다.
