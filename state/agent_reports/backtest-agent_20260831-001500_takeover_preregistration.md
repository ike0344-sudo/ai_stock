# 25위 내 등락률 2등→1등 "탈환" 사전등록 (실행 전 확정, 2026-08-31)

**결과를 보기 전에 이 파일을 먼저 쓴다.** 아래 정의·기준을 실행 후 안 바꾼다.
참고: `kospi-theme-engine/chgtop_swap.py`(교체 순간)·`chgtop_hold.py`(유지
시간)의 **정의만** 빌린다 — 검증 안 된 탐색 스크립트라 결론(초과수익 등)은
안 받아쓴다.

## 1. "탈환" 정의 (chgtop_swap.py의 `was` 필드 개념 재사용)
30초 그리드 스냅샷(오늘 이미 쓴 실제 폴링주기 관례) 기준:
- 그리드 시점 t에서 "거래대금 25위 이내 등락률 1등"인 코드가, **직전
  그리드(t-30초)에서는 2등이었던 코드**인 경우 = 탈환 후보.
  (`chgtop_swap.py`의 `was==2` "2등이 1등을 뺏은 사건" 그대로 채용.)
- **유지조건(HOLD)**: `chgtop_swap.py`가 1분 유지를 요구하는 것과 같은
  실시간 길이(60초)를 우리 30초 그리드로 재현 — t, t+30초, **t+60초**
  3개 연속 그리드에서 전부 1등을 유지해야 유효한 탈환으로 인정한다.
  중간에 다시 뺏기면 무효(노이즈로 버림).
- **진입시점 = t+60초(유지가 확정된 순간)**, 진입가 = 그 시점의 실제
  체결가. 이유: (2)번(실현가능 버전)이 미래참조 없이 실제로 돌아가려면,
  "60초간 안 뺏겼다"는 사실 자체가 60초가 지나야 알 수 있는 정보이기
  때문이다 — t시점에 즉시 진입하면 "유지될지"를 미리 아는 것이 되어
  미래참조가 된다. (1)번(상한측정)도 비교가 성립하려면 같은 진입시점
  정의를 쓴다(조건 하나만 다르게 비교하는 원칙, 오늘 반복 적용됨).

**자유파라미터 개수(정직하게 명시, 사후 조정 안 함)**:
1. 그리드 간격 30초 — 새 파라미터 아님, 오늘 전체 반복 사용된 실제
   폴링주기 재사용.
2. 유지조건 길이 60초(그리드 2틱) — `chgtop_swap.py`의 1분 유지조건과
   동일 실시간 길이로 맞춘 값, 임의로 고른 새 숫자 아님.
3. "탈환"의 범위 = was==2→1만 인정(3등 이상에서의 직행 1등 등극은 불포함)
   — 사용자가 명시한 "2등이던 종목이 1등을 탈환"을 그대로 좁게 해석.

## 2. 두 갈래 실험
**(1) 상한측정(미래참조 있음, 실현 불가능)**: 진입시점(t+60초)에 SHOOT
라벨(60초 안에 +3%, 오늘 지점라벨링과 동일 정의)이 붙어 있는 지점에만
진입. 오늘 이미 돌린 "25위+1등(정적)" 상한과 **나란히** 비교해서 전이가
정적 상태보다 나은지 본다.

**(2) 실현가능 버전(미래참조 없음, 실제로 돌릴 수 있음)**: 진입시점
(t+60초)에 `point_labeling_threshold_rule.detect_activity_burst`
(K=5, 오늘 채택된 값 그대로)가 발동한 지점에만 진입. 방향은 무조건
롱으로 가정하는데, 그 가정이 정당한지 **탈환 시점의 SHOOT/CRASH 비율을
실측**해서 확인한다 — 전체 비율(53:47, SHOOT/(SHOOT+CRASH))과 비교해서
뚜렷이 치우쳐 있으면 그 자체가 방향정보로 볼 수 있다.

두 실험 다 청산·슬롯 제약은 오늘 상한측정(top25+1등 정적)과 완전히
동일 — TIERS(0.03,0.05)/손절-2%(final_strategy 관례, 오늘 사용자 재확인값),
비용모델(수수료+세금+슬리피지), 5슬롯+동일종목병합(simulate_slot_portfolio
재사용).

## 3. 최소표본 기준 (미달이면 억지로 안 돌림)
- **(1) 상한측정**: 30건 미만이면 "표본 부족, 판정 보류"로 숫자만
  참고용 표기하고 결론은 안 낸다. 30이라는 값은 엄밀히 유도된 게 아니고
  "여러 날짜·종목에 걸쳐 나온 것인지 최소한 확인 가능한 수준"이라는
  경험적 감각으로 잡은 값이라고 정직하게 명시한다.
- **(2) 실현가능 버전**: 검증구간(8/21~8/28) **20건 미만이면 판정불가로
  멈추고**, 승률·수익 계산 안 한다(SHOOT/CRASH 비율만 참고로 보고).
  20은 "이항비율의 대략적 치우침(50:50 대비 ±22%p 정도 오차)은 볼 수
  있는 최소 수준"으로 잡은 값 — top25+1등(정적) 실험의 1,000/200 기준
  보다 훨씬 낮은데, 조건 자체가 훨씬 더 좁아질 게 명백해서(그리드시점당
  최대 1건인 정적조건보다, "직전 2등→1등 전이+60초 유지"라는 이중조건은
  더 희소할 것) 같은 기준을 그대로 쓰면 실행 자체가 불가능할 위험이 크다.

## 4. 미리 못박아두는 것
(1)번 결과가 (25위+1등 정적 상한보다) 훨씬 커도, 그 자체로 (2)번이
"채택해야 한다"는 뜻은 아니다 — (2)번의 실제 방향판정(무조건 롱)이
얼마나 정당한지는 §2의 SHOOT/CRASH 비율 실측으로 별도 판단한다.
8월은 이미 홀드아웃이므로 이번 결과도 재현 확인 없이 채택 근거로 못
쓴다는 원칙은 오늘 다른 실험들과 동일하게 적용된다.
