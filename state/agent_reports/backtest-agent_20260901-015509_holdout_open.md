이 구간(2026-06-05~2026-08-28)은 이후 다시 검증용으로 못 쓴다.

재사용한다(재스캔 안 함 - 결과 동일할 게 뻔한데 다시 도는 건 낭비).
`_holdout_cutoff()`로 재계산한 홀드아웃 시작일 = **2026-06-05**, 편지

## 1. 판정 기준 (실행 전 확정)

**표본 규모(성능 아님, 건수만 확인)**: 홀드아웃 구간(2026-06-05~08-28,
약 84일) 원시 후보 **363건**(슬롯 포트폴리오 시뮬레이션 전, 5슬롯 제약
적용 후 실제 채택 건수는 이보다 작을 것 — 정확한 값은 2번 실행 후 보고).
개별 폴드(45일)가 200건대였던 것과 비교하면 기간이 거의 두 배라 표본
자체는 될 걸로 예상한다.

**최소표본 문턱**: 슬롯 시뮬레이션 후 **채택(taken) 거래 30건 미만이면
판단보류**로 끝낸다(그 아래로는 승률/PF가 개별 거래 한두 건에 크게
흔들린다 — `MIN_TRAINING_SAMPLES=50`보다 낮게 잡은 건 ML 학습 표본이
아니라 포트폴리오 평가 표본이라 기준이 다르기 때문, 임의값이지만 명시).

**확증(워크포워드와 일관)**: **total_return_pct > 0 이고 profit_factor
>= 1.0** — 이건 워크포워드 자신의 "합산" 기준선이 겨우 넘겼던 바로 그
문턱(PF 1.006~1.021)과 같은 잣대를 홀드아웃에도 그대로 적용하는 것이다.
ML on/off 둘 다 각자 이 기준으로 판정한다.

**실패(재현 실패)**: **total_return_pct <= 0 이거나 profit_factor < 0.80**
— 0.80은 관측된 개별 폴드 중 최저치(0.828)보다 살짝 낮은 값이라, "개별
45일 폴드 중 제일 나빴던 것보다도 못하다"는 뜻이 되게 잡았다.

**혼조(그레이존)**: 위 두 기준 사이(예: 수익률>0인데 PF가 0.80~1.00
사이, 또는 그 반대) — 이 경우 "확증도 실패도 아니다"로 있는 그대로
보고하고 억지로 어느 한쪽으로 결론짓지 않는다.

**두 ML 설정(off/on 0.3) 각각 독립적으로 위 기준을 적용한다** — 하나가
확증이고 하나가 실패여도 둘 다 그대로 보고한다(유리한 쪽만 골라 쓰지
않는다).

## 4. 종합 — 워크포워드와의 관계
**ML off·ML on(0.3) 둘 다 사전 등록한 "실패" 기준에 해당한다.** ML게이트가
손실 폭을 줄이긴 했다(-23.35%→-14.90%, PF 0.719→0.803, MDD 27.3%→18.8%
— 방향은 워크포워드에서 본 "ML이 나쁜 후보를 어느 정도 걸러낸다"는 패턴과
일치)지만, 두 설정 다 수익률 부호 자체가 마이너스라 "워크포워드와
일관됐다"고 할 수 없다. 워크포워드 6개월 합산은 +1.66%(ML on)/+6.35%
(ML off)로 플러스였는데 홀드아웃 3개월은 정반대 방향(-14.90%/-23.35%)이
나왔다 — **표본 외 구간에서 전략의 엣지가 재현되지 않았다.**

## 5. 한계 (지시대로 명시)
- **3개월치 자유도가 작다** — 247건(ML off)/238건(ML on)은 개별 폴드
  (200건대)와 비슷한 규모라 "폴드 하나짜리" 수준의 불확실성을 안고 있다.
  이 구간 하나만으로 전략이 완전히 죽었다고 단정하기엔 표본이 여전히
  제한적이다(다만 최소표본 문턱 30건은 넉넉히 넘겼다).
- **생존편향** — 로컬 유니버스는 현재 살아있는 종목만 포함한다.
- **일회성 소진** — 이 구간은 이제 검증에 다시 못 쓴다. 향후 같은 전략을
  재평가하려면 새로운(아직 지나지 않은) 기간이 쌓이길 기다려야 한다.
- 지시대로 **결과를 보고 조건·파라미터를 바꾸지 않았다.** "다음에 볼 것"
  으로만 남긴다(손대지 않음): 월별 손익을 보면 ML on의 07월만 유일하게
  플러스였다 — 우연인지 특정 시장 상황(변동성 국면 등) 때문인지는 이번
  조사 범위 밖.
